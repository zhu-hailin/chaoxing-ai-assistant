# 平台标识来源

这五个标识直接下载自品牌官方网站及其页面引用的官方 CDN；没有绘制、生成或使用第三方重画图标。下载日期为 2026-10-13，原始地址与 SHA-256 见 [provenance.json](provenance.json)。

DeepSeek、Kimi 的 ICO 转为原尺寸 PNG；GLM 的 `.ico` 响应实际为 PNG，同样只重新无损编码。原文件保留用于核对，图案与像素不作修改。OpenAI SVG 与 Qwen PNG 直接使用原始字节。标识仅用于识别配置的平台，相关品牌及商标仍属于各自权利人。

运行时使用 `sources/provider-logos.js` 中内嵌的 data URL，不向这些网站或任何图标服务请求图片。

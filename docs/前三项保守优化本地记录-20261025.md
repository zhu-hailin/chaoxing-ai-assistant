## 实现与兼容边界

1. **字体字典内置**：Table 原始 JSON 固定在 `vendor/font/table.json`，共 355,427 字节、20,906 项。构建校验哈希并作为 JSON 字符串内嵌，首次解码时解析。移除外部 Table 资源声明与对应读取权限；Typr、MD5、字形计算、映射值类型与失败时的原文保留流程沿用原逻辑。
2. **内嵌 Logo 瘦身**：原始 1254×1254 RGBA 图像原样保留；固定派生 176×176 浮窗 PNG（29,473 字节）与 32×32 元数据 PNG（2,165 字节）。两者通过 Data URL 内嵌，完整元数据区为 4,382 字符，符合当前更新器的 16,000 字符限制。44px 点击区域、透明样式和交互源码保持原样。
3. **单次解析查询去重**：每次题目图解析建立私有媒体索引，按文档懒加载全部同 ID 节点与 label/control 索引。同一次解析内复用，下一次重新建立；保留隐藏节点、跨题节点、ARIA 原始顺序及独立内容解析的旧查找路径。快照校验、500ms 巡检、异步返回检查、原生写入与回读源码保持原样。

构建只读取本地固定资源，并采用同目录临时文件写完后原子替换。资源缺失、哈希变化、JSON 损坏及图标故障场景均核对了旧产物保留。

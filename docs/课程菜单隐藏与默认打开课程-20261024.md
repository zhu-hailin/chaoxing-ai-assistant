# 课程菜单隐藏与默认打开课程

日期：2026-10-24。仅维护主脚本，版本 1.30。

## 使用范围

- 具体课程页：“其他功能 → 课程菜单”按原生顺序展示逐项开关；开启隐藏对应左侧项目，关闭恢复。“打开”按钮重新读取并点击对应原生入口。隐藏设置持续保存并同步，实际显示项目取决于当前课程菜单。
- 个人空间：“其他功能 → 默认打开课程”，初始关闭。开启后，下次访问 `https://i.chaoxing.com/` 或 `/base` 时自动点击原生“课程”菜单。开启当次不立即跳转；手动选择栏目后保留当前选择。
- 个人空间的原生侧栏保持原样。菜单隐藏只在顶层具体课程首页及已有学习页识别范围内启用，章节、测验等 iframe 不重复创建此功能。

## 实现

- `sources/platform-menu.js` 集中处理页面资格、原生菜单解析、隐藏状态及个人空间默认入口。优先识别已确认的课程菜单结构，同时按左侧位置、独立菜单行及菜单分组识别其他布局；实际菜单名称、数量、顺序及原生节点动态读取。
- 隐藏偏好使用独立 GM 键，按名称及原生菜单标识／路径保存，不保存账号、课程参数值或凭据。仅在识别的原生行上设置独立隐藏标记；不删除节点或覆写原生内联样式，关闭及页面卸载时还原标记。
- 菜单替换、属性更新、窗口缩放及前进后退触发重新识别；旧课程身份失效时恢复旧标记。原生未开放项目保持禁用，刷课或分析运行时禁止通过新增“打开”按钮切换菜单，并沿用现有禁用反馈。
- 个人空间默认入口等待页面及 iframe 就绪，最多等待 15 秒，只点击唯一识别的原生“课程”入口一次；已在课程列表时结束，手动导航时取消。刷新作为新一次访问；浏览器缓存恢复页面时不再次触发默认切换。未识别或未确认打开时在开关下方显示状态。
- `sources/other-features.js` 接入独立管理器并处理页面恢复后的重新绑定，保留原有 AI 助教隐藏与视频保护设置。`sources/assistant-status.js` 同步新增打开按钮的运行资格。模板仅增加对应功能区及紧凑响应式样式，主构建清单纳入新模块。

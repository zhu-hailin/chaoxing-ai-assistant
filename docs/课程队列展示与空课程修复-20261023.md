# 课程队列展示与空课程修复

日期：2026-10-23。版本保持 1.30。

## 用户现场依据

- 课程列表右侧原有任务点数量需要改为进度条。
- “大学英语AIII”章节页显示原生任务统计 0/0 和“暂无章节内容”；助手仍将其判定为加载中，启动等待没有结束。
- 课程选择区偶发为空、全选禁用，面板显示正在连接课程列表。该截图展示连接未就绪；本次没有执行浏览器复现。
- 跨课程队列进入实际课程后，需要展示章节层级，并在标题栏标记“课程模式”。

## 实际改动

- `sources/course-run-preview.js`：课程列表右侧使用原生 progress 元素显示比例和百分比，悬停显示原始任务点数量；已完成为绿色，未知进度使用灰色占位和“待核对”。已在当前队列确认无章节的课程显示“无需刷课”；若原生列表更新出实际任务点进度，优先展示原生进度。
- `sources/panel-template.html`：补充紧凑进度条、连接占位和小型重连按钮样式；增加橙色圆角“课程模式”标题标签。保留原字体、主题、拖动、缩放及第三张卡片的局部模糊。
- `sources/course-home-launch.js`：仅在文档加载完成、存在可见的原生“暂无章节内容”、没有章节项且任务统计明确为 0/0 时，将空目录视为已就绪；通过原私有目录通道传递 empty 状态，并校验空目录字段一致性。章节页加载状态变更时重新发布目录，监听随绑定清理。
- `sources/course-queue.js`：空目录启动沿原完成交接返回课程列表，使用独立 no-tasks 状态保存“无需刷课”，继续下一门；重试及已处理队列前缀均保留这个结果。
- `sources/course-controls.js`：重试资格排除已确认的空课程；课程列表未就绪时沿现有禁用反馈显示实际连接原因。
- `course_catalog.js`：已确认的空目录显示“暂无章节，无需刷课”。
- `sources/course-list.js`：连接失败后在同一轮最多重建三次，每次最多 15 秒、总预算最多 45 秒。子页原生入口就绪时只发送一次就绪通知，父页核对当前 iframe、来源和地址后按需重新连接；替换及迟到回调仍按现有绑定对象身份退出。用户主动重连开启新一轮，正常点击进行中的入口不延长期限。

课程列表页预览课程队列；进入具体课程后预览当前和后续章节。标题标签反映外层课程队列仍在运行，展示变化不更改课程队列、章节执行器和任务归属。

空课程状态由原生目录证据确认。缺少课程列表进度时先按原生入口进入并读取目录；不根据缺少进度单独判定空课程。空课程处理不创建视频、模型或答案写入请求，不计为用户跳过或任务点完成。

保留原课程、班级、cpi、标签页、运行轮次及模型签名关联，自动提交授权、停止和人工验证等既有流程保持原样。未修改 README、版本、接口候选版、配套扩展及发布目录，未提交或发布。

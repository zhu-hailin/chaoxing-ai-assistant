日期：2026-10-26。保持脚本版本 v1.31，本地交付。

## 修改范围

生产源码仅修改 `sources/course-runner.js`：新增内部时限 emptyTailWaitMs=2500，并替换栏目全部遍历结束时的确认等待调用。pollMs=500、settleMs=700、completionMs=30000 保持原值。

快路径要求当前真实栏目为最后一栏，全部栏目已遍历，该栏最近一条任务记录为 non-task/not-required；框架可读且加载完成，声明地址与实际地址相符，并在重新读取后仍无必做控件或可见任务点。current 临时占位栏目不使用短窗口。

等待内每轮复用原守卫与取消等待。新栏目出现后交回原遍历；当前无任务页出现必做控件或任务标记后，撤销当前页已遍历记录、清除该章预读缓存、保存原结构的栏目进度，再由原任务流程读取处理。新增真实任务处理后，其最新记录替代无任务记录，避免重复回到同一页。

短窗口与完整确认窗口从同一时刻计时。栏目签名、主/子文档身份、正文节点、文档 URL、加载状态或目录状态变化后，永久退回本次等待的原 30 秒截止时间，不重新续期。新任务与新栏目检查在超时判定前进行。

到期仍使用原 COURSE_TIMEOUT 异常，由原超时继续设置与失败计数分支处理；目录完成标记更新时正常结束等待。人脸、验证码、账号/章节/栏目切换及不可读框架等既有守卫仍直接按原规则处理。

## 静态审查记录

| 场景 | 源码路径与预期处理 |
|---|---|
| 已遍历的真实无任务尾页，目录仍有待完成数 | 2.5 秒短截止时间，前序 700ms 稳定等待保留 |
| 最后栏目仍有真实任务、仅占位栏目、页面仍加载 | 使用原 30 秒窗口或原任务流程 |
| 等待中新增栏目 | refreshTabs 后 nextTab 返回，继续原遍历 |
| 当前无任务末页新增任务 | 撤销已遍历记录并重读控件，原完成标记负责去重 |
| 加载、栏目签名或文档身份变化 | 同一起点的完整截止时间，原身份异常守卫优先 |
| 目录完成数归零或出现完成标记 | 正常结束等待；新增可执行任务先交回原流程 |
| 短/长窗口到期 | 原超时异常、继续/停止设置及连续失败计数 |
| 停止、取消、人工切换、提交结果不明 | 复用原 guard/wait 及后续异常处理 |

本轮只执行源码、调用链、差异静态审查和必要构建，未运行测试、语法检查、离线模拟、浏览器功能验证或真实课程操作。上表为静态分支审查，不是运行测试结果。

真实课程效果由用户人工验收，观察截图中的“正在核对新增栏目或平台完成确认…”阶段。平台任务仍未完成时，保留实际状态，并按原设置处理后续章节。

## 源码修复

修改 `sources/course-list.js`：

- 原父页握手 15 秒到期后只清除定时器，失效绑定仍被当作当前绑定，入口又完全依赖子页绑定而禁用。现在一次连接等待固定上限 45 秒；显示超时原因，用户再次点击入口时重建连接。普通 DOM 更新及重复点击进行中的入口不延长本次期限。
- 打开面板通过当前 iframe 的内部消息进行，只接受限定课程列表来源、当前 `frame_content` 窗口和支持的声明地址；入口点击仍核对可信操作、工具栏及相邻节点。此消息只打开界面、恢复连接，不承担选课、导航或启动授权。
- 课程卡片同步、原生入口核对和队列启动继续使用原私有 GM 记录，保留标签页、文档、完整地址、课程、班级、cpi 及命令有效期校验。
- 子页先监听私有绑定记录，再等待标签页读取并选择最新的私有变更值。相同绑定只保留一个进行中的核对，过期或被替换的异步结果退出；离页清理监听和等待定时器。
- 父页异步回调须匹配当前绑定对象；旧回调不会重新启动旧连接或清理新连接。
- 文档根节点增加 `data-cx-course-list-connection`、`data-cx-course-list-reason` 供只读命令查看。只记录连接阶段及简洁原因，不公开私有存储、课程身份、API Key 或自动提交授权。

修改 `sources/course-run-preview.js`：

- 列表未就绪时展示实际连接原因；就绪后恢复原选择提示。
- 结果区显示原记录保存的队列停止原因，并提供 `data-queue-phase`。保留逐门报告，沿用“重试未完成”，不自动重新运行已停止队列。

不改变运行器、视频播放、测验、自动提交授权、模型配置及课程完成规则。第一门成功结果沿原存储保留。

## 只读诊断命令

安装本次构建并刷新个人空间后，在控制台选择 `top` 执行。命令只读取 DOM，不触发导航、刷课、重试或存储写入。

```javascript
(() => {
  if (window !== top) return console.log('请在 top 控制台执行');
  const read = doc => {
    const state = doc.documentElement.dataset;
    const panel = doc.getElementById('cx-ai-study-root')?.shadowRoot;
    const entry = doc.getElementById('cx-ai-course-list-entry')?.shadowRoot?.querySelector('button');
    return {
      连接阶段: state.cxCourseListConnection || '尚未初始化或仍为旧脚本',
      连接原因: state.cxCourseListReason || '',
      队列阶段: panel?.getElementById('course-queue-results')?.dataset.queuePhase || '',
      停止原因: panel?.getElementById('course-queue-result-list')?.textContent.match(/^队列已停止：[^\n]*/)?.[0] || '',
      可选课程数: panel?.querySelectorAll('.course-choice').length ?? null,
      入口禁用: entry?.disabled ?? null
    };
  };
  let child;
  try {
    const doc = document.getElementById('frame_content')?.contentWindow?.document;
    child = doc ? read(doc) : { 状态: '未找到课程 iframe' };
  } catch (error) { child = { 访问异常: error.name }; }
  console.log('连接恢复诊断：\n' + JSON.stringify({ 顶层: read(document), 课程iframe: child }, null, 2));
})();
```

# 学习通 Cookie 字段说明

日期：2026-10-26。仅列字段名，不保存截图原值。

Cookie 由网站保存在浏览器中，浏览器按域名、路径和安全属性附带到相关请求，用于会话、状态或业务上下文。一般机制参考 [MDN：Using HTTP cookies](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Cookies)。

超星专有字段未找到完整公开定义。下表区分标准含义与结合当前页面、字段名称及值形态作出的推断，不解释未公开的编码算法或枚举。

| 字段 | 说明 |
| --- | --- |
| UID、_uid | 平台用户标识；在账号界面按用户 ID 展示，不映射为学号。 |
| fid、spaceFid | 单位／当前个人空间单位标识。当前学校名称从个人空间 #siteName 单独读取，不根据数字猜学校。 |
| siteRole、spaceRoleId | 当前站点／空间角色的数字标识；身份名称从平台现有文字读取，不硬编码数字与学生、教师的对应表。 |
| schoolId | 名称涉及学校上下文，但与 fid 是不同字段，具体映射未确认。 |
| cx_p_token、p_auth_token | 认证令牌类字段；p_auth_token 的可见前缀具有 JWT 的外观。应按登录凭据处理，不进入头像资料页。 |
| JSESSIONID | Java Web 常用服务器会话标识，标准名参考 [Tomcat SessionConfig](https://nightlies.apache.org/tomcat/tomcat-10.1.x/coverage/org.apache.catalina.util/SessionConfig.java.html)。 |
| jrose、jrosehead | 推测与不同服务的会话上下文有关，具体实现未确认。 |
| route、k8s | 推测与后端节点路由、负载均衡或会话黏滞有关。 |
| examinationRole | 推测是考试角色／权限上下文，具体格式未确认。 |
| roleEnc、spaceFidEnc | 名称提示角色／单位上下文的编码或校验值；不能据 Enc 字样确定算法。 |
| jpenc、jpsign | 名称提示平台编码／签名字段，具体语义未公开。 |
| uf、vc3、xxtenc | 平台内部会话或校验类字段的候选；本次未确认其具体用途。 |
| DSSTASH_LOG | 推测是日志／追踪关联字段。 |
| _d | 值形态类似毫秒时间戳，具体触发条件和用途未确认。 |
| _industry、tl、space_version、source | 业务或空间界面的上下文标志；具体枚举值未确认。 |

同名 Cookie 可以按不同域或路径分别存在。截图中不同服务拥有同名、不同值的条目，这符合 Cookie 的作用域机制；.chaoxing.com 域下的 Cookie 可在符合条件的子域请求中使用，具体域名下的条目受对应作用域约束。参考 [MDN：Set-Cookie](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。

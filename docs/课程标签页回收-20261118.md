# 课程标签页回收（2026-11-18）

课程顶层文档收到 `resume` 时唤醒当前自动学习视频的等待，并让独立播放恢复和「视频不暂停」重新检查媒体状态。重新加载后，只有顶层文档的 `wasDiscarded` 为 `true` 时才在课程面板显示回收提示。

后台课程播放或自动学习期间，脚本收到原生 `freeze` 事件后通过 `GM_notification` 请求发送系统提醒。Windows 的通知和横幅设置决定弹窗是否出现。直接回收没有页面事件，重新加载后通过面板显示回收状态。

长期挂机可在 Chrome「设置 → 性能 → 始终让这些网站保持活动状态」添加当前课程网站。标签页回收由浏览器管理。详见 [Chrome 性能设置](https://support.google.com/chrome/answer/12929150?hl=zh-Hans) 和 [页面生命周期说明](https://developer.chrome.com/docs/web-platform/page-lifecycle-api)。

本地版本维持 v1.34。仅进行源码静态审查和主脚本构建，未运行测试、语法检查或浏览器验证。

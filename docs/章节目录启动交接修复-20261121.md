# 章节目录启动交接修复

截图已显示「线性代数 A」原生章节目录。本次修正目录已显示而原生章节入口尚未加载完成时的启动分支。

- 启动仍按原目录顺序与跳过已学设置挑选目标。对未锁定但尚未有可用入口的目标，最多等待十秒，原生 `toOld` 处理函数和服务器地址就绪后再点击。明确锁定立即走原处理分支。
- 子页读取首页已绑定的标签页启动记录。同一启动只保留一次进行中的核对，实际点击后不会重复触发。原生入口打开新标签页时，交接也读取最新的标签页绑定。
- 首页打开助手面板展示终止原因，区分等待原生入口超时和点击后仍未进入学习页。学习页仍验证原身份、原目标章节和队列授权后启动。

# 课程滚轮与空课程状态同步

版本保持 1.30，主脚本本地交付。

## 界面与队列

- `sources/panel-template.html`：刷课页分为“待刷列表、刷课设置、章节目录”。第一栏只显示运行队列组件和必要空状态；第二栏容纳课程选择、开始／停止／跳过／暂停、原有选项、间隔设置与结果；章节目录 DOM 和操作沿用原样。
- `sources/course-run-preview.js`：将三张预览卡片改为完整队列滚轮。课程列表范围读取已选课程或本轮课程队列；实际课程内优先读取与当前运行锁一致的完整章节队列，回退到既有章节预览选择逻辑。标题和状态按课程 key／章节 ID 对应。
- 滚轮用原生滚动与 CSS 吸附；中间行高亮，上下条目缩小、旋转并淡出。滚动、点击居中、上下方向键和 Home／End 仅改变浏览位置，任务顺序及运行权限仍由原队列和执行器决定。真实任务切换时居中到当前项，其他状态刷新保留浏览位置。窗口尺寸变化重新计算首尾留白，离页清理观察器和动画帧。
- `sources/assistant-navigation.js`：增加待刷列表页签，默认打开该栏；方向键只在可用页签之间移动。个人课表仍禁用章节目录并保留反馈。设置及任务执行继续使用原有元素 ID 和绑定。

## 加载条修正

用户截图中的提示位于上方课程选择区，前次只给下方预览空状态增加了 progress。本次在实际 `.course-choice-empty` 提示下添加循环加载条，滚轮空状态也复用同一主题样式。加载条表示正在连接，不展示推测百分比；连接成功或错误后退出加载状态，失败沿用重新连接按钮。减少动态效果偏好下显示静态指示条。

## 空课程状态同步

用户现场只读诊断确认大学英语 AIII：文档 complete、原生任务点 0/0、无章节项、可见“暂无章节内容”、统计区存在，且未出现登录或验证阻挡。此前此证据只进入刷课启动记录，普通查看课程后返回课表时没有对应空课程记录，导致仍显示待核对。

- `sources/course-home-launch.js`：复用现有目录解析和验证阻挡判定，保存课程／班级／cpi 对应的原生目录观察记录。空课程仍需全部原有证据，缺少进度本身不推断为空。记录有效期 24 小时，同一结论五分钟内合并写入；明确检测到章节或正数任务总量时，撤销此前的空课程状态。
- `implementation.js` 及章节页 readyState 监听：普通打开章节页即可采集，沿用现有 DOM 刷新，不要求点击开始。
- `sources/course-list.js`：课表监听私有 GM 通知并按身份更新内存观察记录；通知携带记录本身，处理不同存储键传播先后次序。现有连接清理同步移除监听。
- `sources/course-run-preview.js`：课程选择区对原生进度缺失的课程读取对应记录，显示“无需刷课”；明确新增章节记录覆盖旧空结果。此记录只供界面提示，启动、权限和换课仍读取当前原生页面。

安装本次脚本后，正常打开或刷新该空课程的章节页一次，再返回课表即可记录并显示“无需刷课”。此前控制台诊断为只读，不会写入脚本存储。其他没有取得空目录证据的课程继续显示待核对。

## 原因与修改

原导航在找不到当前测验时直接返回，题目图标仍显示为普通可点击按钮，造成无反馈的外观。

业务逻辑仅修改 implementation.js：

- 复用现有题目节点检测和当前课程 iframe 树查找，设置原生 disabled、aria-disabled、键盘焦点顺序及标题；沿用已有禁用样式。
- 无可用题目时禁止侧栏进入题目页面，首次打开默认使用刷课页。存在当前测验时继续交接到其控制器。
- 侧栏方向键及 Home、End 只选择可用栏目。
- 在现有状态渲染和 DOM 刷新中重新读取可用性；iframe 加载及测验文档刷新通知顶层面板，文档离开后延迟至当前帧树更新再读取。没有新增轮询。
- 新增事件只刷新导航状态，不携带题目、答案或执行任务；离开页面时清理监听。
- 保留 sourceDoc、窗口交接、题目与答案、分析进度、预填安全检查及课程运行状态。

构建入口、脚本元数据、面板、文档桥、结果数据、npm 和预览相关版本同步为 1.28.3；测试源仅同步版本引用，未执行测试。README 保持不变，通过 prepare_publish.py --skip-readme 同步。

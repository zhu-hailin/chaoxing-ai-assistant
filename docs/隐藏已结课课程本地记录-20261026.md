# 隐藏已结课课程

日期：2026-10-26。保持本地 v1.31，未发布。

## 用户需求与识别边界

用户要求在“其他功能”增加开关，隐藏截图中封面明确显示“课程已结束”的课程。截图中另一门任务点 15/15 的课程没有该封面标记，应继续显示。

现有课程适配器通过课程列表的 .not-open-tip 判断“课程已结束”，但它同时要求有效学习入口和 course.learnCourse 卡片结构。显示筛选直接读取 #courselistArea 内 .not-open-tip 的准确文字及其最近 .course 卡片，覆盖没有可用入口或 learnCourse 类的结束卡片，不改原有课程列表解析与队列数据。

忽略 template、hidden、aria-hidden=true 中的标记。按封面状态判断，不根据课程名称、年份、时间范围、百分比或截图中的排列顺序推断结课。平台自带筛选的内部条件未作结论。

尝试只读查看当前个人空间并打开课程列表栏目；列表框架当时正文为空，未采集到这几张卡片的实时 DOM。本轮依据用户截图与现有课程源码完成适配，未进入任何课程。

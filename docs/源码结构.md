# 源码结构与修改入口

## 开发和安装

开发源码按职责维护，`python build_script.py` 将有序清单中的文件构建为根目录 `学习通AI助手.user.js`。用户仍安装这一份完整文件。

`build_script.py` 中的 `SOURCE_FILES` 列出公共能力和课程能力，`IMPLEMENTATION_FILES` 列出助手应用与页面启动部分；清单同时决定装配顺序。新增源码需要加入相应清单，单独放进 `sources/` 不会自动参与构建。

## 状态与依赖约定

- 每个原文档仍保留原控制器及题目绑定；窗口交接改变显示位置，保留 `sourceDoc` 和任务归属。
- `createAssistantController()` 是宿主装配入口，将现有界面、分析和题目命令传给 `createController()`。
- 控制器使用 `getPanel()`、`getUiHidden()` 读取最新窗口状态，避免在异步操作开始时冻结面板引用。
- `initCourseRunControls(doc, ctl, view)` 明确接收所属面板，控件回调与清理继续对应同一组 DOM。
- 分析会话继续使用已有取消器、任务轮次、逐题结果和快照；课程执行器保留原有状态机。
- 新文件仍装配到原用户脚本闭包。这轮整理没有改为浏览器 ESM 或建立第二套扩展实现，部分跨功能调用继续保留原名称。
- `assistant-core.js` 的 document-start 播放保护调用依赖函数声明提升；后台播放模块保留函数声明，页面启动入口位于装配末尾。不要单独用 IIFE 包住迁移函数，或随意调整顶层初始化顺序。

## 构建、预览与发布

- 日常交付只需必要的完整脚本构建，不附带运行测试。
- 预览生成器继续读取完整用户脚本。课程资料专项源码引用改为 `sources/course-context-collector.js`。
- `prepare_publish.py` 会把 `sources/` 第一层源码加入发布清单，随后发布目录的构建使用相同有序清单；只在用户授权上传后同步发布。
- 测试、语法检查及浏览器验证按 `AGENTS.md` 的明确授权规则执行。

此次内部整理保持现有设置、界面文案、识别和原生写入规则、播放参数、分析与停止流程。重复快照解析优化、ESM 构建和独立扩展属于其他变更范围。

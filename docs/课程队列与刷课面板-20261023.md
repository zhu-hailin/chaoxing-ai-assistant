# 课程队列与刷课面板

日期：2026-10-23。版本保持 1.30。

## 实现范围

- 课程列表入口位于个人空间“学习规划助手”左侧，同排显示；在实际课程 iframe 本地挂载，顶层复用原助手面板。
- 课程列表启动前勾选课程，按原列表顺序运行，复用当前标签页。单课程首页、章节与学习页启动仍仅处理本课程。
- 新增课程队列外层调度；每门课经原生课程链接、现有首页启动交接进入现有运行器，章节和任务处理逻辑保持原链路。

## 生命周期及状态

- 队列保存在私有 GM 存储，绑定标签页、课程／班级／cpi、当前项目和随机轮次。实际课程入口每次从当前原生列表重新读取，API Key 不进入队列记录。
- 一次课程启动继续使用原有 120 秒交接期限。进入下一门创建新的交接；课程中转页也保留有界等待，异常时停止并显示原因。
- 运行器的 `done` 结合各章节真实状态分类。全部完成、仍有待办及待解锁分别保留；验证码、人脸、身份变化、运行锁失败、提交未确认及保护性停止中止整个队列。
- 下一门调度在原运行器 Promise 完成、释放同课程运行锁之后执行。章节换页仍属当前运行，旧轮次返回结果不推进队列。
- 确认停止先撤销后续启动权限，再停止运行器。跳过课程需满足当前任务可安全中断且没有待确认提交的条件。
- 自动提交仅属于本次明确选择的课程集合；改变选择使原授权失效，重试重新取得本次授权。普通恢复保留现有自动提交权限处理规则。
- 跨课程传递累计活动时间和休息截止时间，下一门已到休息门槛时先沿用原休息流程。

## 面板

- 最多显示三张：课程队列显示课程，单课程显示章节。仅第一张左侧带“当前”，标题对齐，长标题省略并可悬停查看。
- 卡片最小高 64px、间距 8px、内边距 12px、圆角 8px。第三张上半清晰，下半局部 4px 模糊并渐隐至白色；其他界面背景不变暗。
- 删除旧的常驻刷课说明和保护开关状态。真实停止原因继续进入现有底部状态及运行报告。
- 倍速问号独立于复选框；说明保持原规则：原生最高且不超过 2 倍，开启视频信息识别时保持原速。

## 人工验收项目

1. 个人空间入口位置正确，列表刷新、iframe 替换后只有一个入口；已结束课程禁用反馈正常。
2. 勾选两门可学习课程，从列表启动后依序处理；从单课程入口启动后仅处理本课程。
3. 原生课程中转、同标签页跳转、慢加载和章节换页恢复正常；重复点击与旧响应不重复启动。
4. 已完成课程跳过、关闭跳过已学后从头学习、待解锁边界及人工待办结果正确。
5. 关闭超时继续、触发失败保护、验证码、人脸或提交未确认时停止整个队列；停止和跳过课程后不误启动。
6. 队列重试保留已完成结果；更换选择、账号、课程身份及模型配置后原授权不会套用。
7. 单课程和课程队列卡片切换正确；第三张半模糊、窄窗口滚动、拖动缩放及倍速问号交互符合预期。
8. 原有播放、视频间隔、休息、题目分析、预填及手动停止流程保持可用。

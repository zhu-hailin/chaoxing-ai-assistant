# 首页目录导航命令同步

## 证据与原因

用户在章节 iframe 执行诊断：页面为 `/mooc2-ans/mycourse/studentcourse`，原生 `toOld` 函数存在，识别到 40 个原生章节。点击助手目录后，1.56 秒收到来自真实父窗口、来源正确的 `catalog-navigate` 消息，随后没有原生章节点击或执行异常记录。

现场确认消息已到达、执行在原生点击前停止，尚未记录原校验函数具体命中的返回分支。源码中发现确定存在的竞态：父页写入私有 GM 命令后立即发送一次 postMessage，章节页收到后只读一次命令；当消息先于跨帧存储同步到达时，读取为空就直接返回。原实现没有监听命令后续同步，最终只出现父页 5 秒超时。

## 修复

仅修改 `sources/course-home-launch.js`：

- 复用已有资料桥接使用的 GM 值变化监听方式。在章节绑定发布就绪前注册命令监听，直接使用私有存储变化回调中的命令值；保留 postMessage 唤醒，二者进入同一个执行函数。
- 命令暂未读取到时等待存储同步，不清除或放宽关联校验。私有记录仍须匹配连接、文档、标签页、课程／班级／账号及原 5 秒期限；页面地址、原生目录和可导航状态在点击前重新读取。
- 每个绑定用命令 ID 记录一次消费，先登记再执行原生点击，防止消息和存储回调重复触发；按原期限清理已消费记录，关闭或替换绑定时移除命令监听并清空记录。没有增加重复点击或请求轮询。
- 文档、标签页、课程账号、上下文及原生入口不匹配时，通过原私有回执返回简短具体原因及内部原因码；界面继续使用原有底部状态区，无新增弹窗。真实锁定仍保留限制。

页面消息没有获得新的动作权限；命令仍由首页可信点击创建，存储监听只消费已有私有授权记录。原生选择入口、自动学习启动、题目、预填、视频、倍速及其他适配器流程不改动。

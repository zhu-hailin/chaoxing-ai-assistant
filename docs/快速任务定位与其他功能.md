# 快速任务定位与其他功能

本文记录上一候选；定位部分已升级为 4 路有序并发与 60 秒缓存，当前实现见[秒级任务定位](秒级任务定位.md)。下方串行流程及其结果保留为历史记录，“其他功能”沿用。

本地候选基于 v1.20 / npm 1.0.20。保留当前工作区修改，README、`.publish` 和 GitHub 发布状态保持原样。

## 快速定位可执行任务

启动和后续章节使用同一有序定位入口：目录预筛选 → 原生任务摘要 → 栏目定位 → 进入页面复核。关闭章节自动提交时，测验记录为 `manual-pending`，继续处理视频、PPT 和后续章节；平台未完成状态保留。

- 未选“从当前开始”：从课程第一栏目查找。
- 已选：冻结当前章节、栏目 ID、栏目下标及 cardId，排除之前范围；导航恢复、人工重试保留这个边界。
- 只按需串行读取当前课程的同源 `studentstudyAjax` 和 `knowledge/cards`。找到首个可执行或待页面核实的目标即停止向后探测。
- 优先使用当前文档；其他栏目的返回内容只放入脱离页面的 template。静态 `mArg` 经严格扫描和 JSON.parse 解析，兼容已见的 IIFE / try / uParse 包装，不执行返回脚本，不挂载播放器或加载题目、媒体。
- 任务类型、完成状态缺失，空附件、实际 DOM 与摘要冲突、目录待完成数量超出映射范围、网络失败时，回到原有有界页面检查。
- 验证、账号变化、人工导航、停止及不明确的提交状态保留原处理。定位阶段不播放、不请求模型、不提交任务。

运行报告的 locator 字段记录摘要读取请求数、原生章节/栏目切换次数、排除数、回退数和耗时。只读探测未写入平台完成标记。

## 其他功能

左侧第三个入口为“其他功能”，设置仍固定在底部。两个开关默认关闭，使用 `cx_other_features` 保存并在页面实例间同步。

### 隐藏平台 AI 助教

小黄人和 AI 助教入口是同一个 SDK 的两种形态。根据本地 HAR 中的平台 `CxRobotSdkJs.js` 确认组件根节点：

```css
.cx-robot-wrapper, .cx-robot-side, .cx-robot-side-tips
```

开关通过专用样式隐藏组件、气泡和侧栏，包括后续插入的节点；关闭时清除该样式，保留原节点及其内联样式。通用 `.resizer`、任务验证和助手自身界面不参与匹配。

### 视频不暂停

用于课程页手动观看，复用现有鼠标移出保护、可信暂停意图识别、平台门槛和播放进展判断。只在用户先播放视频、且当前只有一个正在播放的视频时绑定，不启动尚未播放的视频。

- 来源未确认的暂停每隔至少 3 秒恢复一次，进行中的 play 请求不叠加；最多连续 8 次，普通播放累计 10 秒后恢复额度。
- 用户可靠手动暂停后等待用户继续；验证码、人脸、视频弹题、明确前台观看要求和不可读任务框架优先处理。
- 自动刷课运行期间让出控制，使用原 runner 播放保护；结束后重新识别手动播放的视频。
- 关闭开关、视频移除、页面退出时清理监听和计时器。全隐藏助手界面不更改这两个功能的保存值。
- 不修改播放位置或速率，不伪装焦点，不调用模型或答题提交。

## 验证与现场验收

详细自动检查结果及模拟性能数据见同目录《快速任务定位与其他功能回归结果.json》和《验证记录.md》。离线场景不调用真实模型，不回放真实账号请求。

换装后在允许操作的课程验收：关闭章节提交后的定位范围、当前第③栏启动、刷新后继续、两种平台助教形态隐藏，以及手动播放时移出鼠标、失焦和最小化后的恢复。后台效果受浏览器调度及当前平台观看条件影响，以实际播放进展观察。

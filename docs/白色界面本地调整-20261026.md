# 白色界面与下拉框样式修正

2026-10-26。保持脚本 v1.31，仅本地交付。

## 原因与处理

原模型设置规则对 select 使用 5px 8px 内边距，覆盖了省略号装饰原先预留的右侧空间；短值 Max 的末尾与装饰靠在一起。边框之外另有 offset 为 2px 的焦点描边，形成双层轮廓。

本轮移除原生 select 的装饰背景图，统一文字内边距，为强度选择器保留 72px 最小宽度。输入框与选择器的焦点描边覆盖边线所在位置，保留单圈可见焦点。

主窗口、标题栏、侧栏、状态栏和弹层表面采用白色，文字和分隔线采用中性灰。绿色用于品牌、主按钮、选中项、答案重点及运行状态。题目布局、菜单、原生下拉交互、模型调用和预填保护逻辑保持本轮之前的实现。

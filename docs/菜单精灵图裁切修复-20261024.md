# 菜单精灵图裁切修复

日期：2026-10-24，主脚本版本 1.30。

用户截图显示章节、讨论、作业等菜单图标截断并混入旁边图形。静态审查发现旧实现将部分原生绘制框强制改为 20px，其他尺寸也会被 22px Flex 容器压缩，背景定位及背景尺寸仍沿用原值；百分比定位的精灵图会因此改变采样位置。

此次仅修改菜单图标快照、渲染及相关样式：

- 快照保留原始宽高、box-sizing、内边距、边框尺寸、background-origin／clip 以及原有背景定位、背景尺寸和遮罩规则；图片保留 object-fit／object-position。
- 原尺寸绘制框放入独立定位的裁切层，退出 Flex 尺寸压缩；按原始盒模型计算边界，裁切完成后使用 transform 整体缩放到 20px 展示范围，并在 22px 槽位中居中。
- 图标按原菜单身份读取，现有菜单打开、隐藏偏好、禁用反馈、图标刷新及个人空间默认课程逻辑保持原调用链。

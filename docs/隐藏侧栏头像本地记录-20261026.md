# 隐藏侧栏头像

日期：2026-10-26。保持本地 v1.31，未发布。

在账号信息页标题右侧加入“隐藏头像”开关，默认关闭。开启后仅将左下角真实头像、姓名字形占位隐藏，替换为内嵌 SVG 人形图标；侧栏标题和无障碍名称改为通用“账号信息”。关闭后恢复原有头像显示及账号名称提示。

账号页内的大头像、姓名、学校、用户标识及进入账号页的导航保持原样。图标完整内嵌，不增加远程图标、脚本或字体依赖。

设置单独保存在布尔键 cx_account_hide_avatar 中，不持久化用户资料。沿用可信控件操作检查，使用 GM 值变更监听跨面板同步；页面退出移除监听，恢复显示时重新绑定并读取设置。资料刷新或头像加载失败时 CSS 显示规则继续优先应用，避免重新露出姓名字形。

# 无任务图书阅读器等待修复

日期：2026-10-26。版本保持 v1.31，仅本地交付。

## 排查依据

只读查看用户已打开的学习页面，未点击栏目、启动刷课、滚动资料或提交答案。当前“西方运动学发展史”栏目没有可见任务点，实际结构为：

1. 主课件内 `.ans-attach-ct`，未发现 `.ans-job-icon` 或 `[data-course-task]`。
2. `iframe.ans-attach-online.ans-book`，路径 `/ananas/modules/innerbook/index.html`。
3. 包装页内 `iframe.ans-attach-online[name="bookifame"]`，来源 `https://resapi.chaoxing.com/innerurlNew`。

旧版 `courseFrameTree()` 只对已适配的 PPT 阅读器和答案编辑器做特殊处理。上述图书阅读器跨域，不能由课程页面直接读取，因而进入 inaccessible 列表。`waitForFrameReady()` 在判断有无任务点之前要求框架全部可读，导致无任务图书也反复提示等待控件，达到原重试上限后停止。

阅读器内的 SaveAs 和 dopagechange 辅助框架具有 `display:none`，不参与原来的可见框架遍历；它们不是本次阻塞原因。截图显示的“自动学习已停止”与原重试耗尽停止路径一致，截图未保留当次完整错误报告。

## 修改与静态审查

生产代码仅修改 `sources/course-page-adapter.js`，添加私有结构识别函数，并在原框架遍历入口使用：

- 限定叶框架名称、class、HTTPS 精确来源和固定路径，外层须是受支持课程域名下的 innerbook 包装框架，实际包装文档与声明路径一致。
- 外层附件及包装页必须没有可见任务标记；即使存在 `data-isjob=false`，新增可见任务标记仍阻止放行。
- 包装页仍在加载、显示验证码、人脸、登录、作业或加载提示时继续原有检查。
- 每次重新读取结构与标记，不缓存“无任务”结果。未知框架、非匹配来源和路径、有任务的图书保留原处理。
- 框架树仍包含课件主文档和 innerbook 包装文档，由现有 `coursePageWithoutTasks()` 记录 non-task/not-required 并继续后续栏目；未改写平台完成标记。

调用链静态审查覆盖 `courseContentReady()`、`courseTaskTargetReady()`、守卫、无任务判断、定位流程及尾页确认。此前 2.5 秒尾页窗口、700ms 稳定检查、正常任务的确认及超时策略均保持原实现。题目上下文的框架检查未修改。

补充了一项未执行的回归用例，覆盖匹配的无任务图书、空白阅读器子框架、不可读阅读器、新增任务标记、冲突的非任务属性、未知来源和错误路径。

本轮执行源码及差异静态审查、现场 DOM 只读排查和必要构建；未执行测试、语法检查或修改后的浏览器功能验证。真实课程效果由用户验收。

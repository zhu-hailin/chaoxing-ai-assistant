# 首页目录同步与未完成任务直达

版本保持 1.30，基于本地最新源码修改，保留此前首页入口、禁用反馈和现有刷课执行流程。

## 实现

- `course_catalog.js` 接入首页目录来源，复用原目录组件的分组、折叠、搜索、完成比例与章节按钮。首页定位按钮显示“定位未完成”，清除搜索、展开所属分组并短暂高亮；学习页仍定位当前章节。
- `sources/course-home-launch.js` 读取身份一致的实际章节 iframe。按原生章节 ID、标题及 DOM 顺序生成条目；完成标记、剩余任务数、明确锁定与原生导航能力独立解析。缺少完成证据时保留未确认，缺少导航证据时保留入口未确认。
- 原生 `toOld(...)` 与已支持链接继续严格检查课程、班级、章节身份及受支持来源；只点击原节点，不构造章节请求。目录折叠和搜索不改变选择范围。原生入口自身的权限判断继续生效。
- 同一选择函数供首页定位和启动使用。默认跳过已学，只跳过已确认完成或无任务点的前缀；首个未完成或需核对章节为目标。关闭开关时选择首章，沿用原队列逻辑。全量完成标记与首页任务总计矛盾时继续等待目录，不宣称完成。
- 交接记录增加确认过的前缀，学习页再次比对 ID、顺序与剩余任务状态；有矛盾时取消直达起点，交回原定位器。内部 `startChapterId` 只裁剪章节前缀，不设置当前栏目范围，因此仍检查整章全部栏目；恢复沿用原持久队列，不新增公开插件参数。
- 首个目标待解锁或入口未确认时以边界状态结束启动，不遍历后续章节，不创建失败或跳过任务。学习页后续继续使用原解锁等待、运行锁和停止机制。
- 目录观察器跟随实际 iframe 及内容根节点；来源、身份或文档替换后重新读取。异步交接在实际导航前再次选取目标，同一请求的导航只领取一次；过期、取消、模型配置和账号变化继续中止。
- 点击首页目录只执行原生导航；自动学习仍须使用“开始刷课”的原授权与一次性交接。

辅助接入修改 `implementation.js`、`sources/assistant-navigation.js`；小范围增加 `sources/course-runner.js` 内部起点参数，原定位、视频、资料、测验、倍速、预填与提交流程保留。

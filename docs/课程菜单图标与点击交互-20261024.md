# 课程菜单图标与点击交互

日期：2026-10-24；主脚本版本保持 1.30。

## 修改

- `sources/platform-menu.js`：从已识别的原生菜单目标读取图标，支持原生图片、CSS 背景／遮罩、伪元素图标字体及基础 SVG 几何。构造仅用于显示的图标节点，保留原始资源样式；SVG 仅复制允许的几何节点及属性，移除事件与外部引用。菜单刷新时读取图标，平常状态渲染复用快照；原生图片加载及图标属性变化触发刷新。
- 列表展示改为独立隐藏复选框与图标／名称点击区域，移除可见“打开”按钮。点击菜单仍重新核对页面范围、当前原生目标及运行资格，再调用原生节点点击；勾选只更新隐藏偏好。沿用原来的存储键与项目身份，显示名称单独去掉尾部 NEW。
- `sources/panel-template.html`：收紧行间距，图标区域 22px、图片和 SVG 20px，名称单行省略；点击区域保留键盘焦点，图标作为装饰隐藏于辅助技术，隐藏复选框有独立无障碍名称。禁用反馈沿用现有实现。

## 默认打开课程反馈

用户反馈上一轮个人空间开关没有生效。静态检查发现此前入口依赖整组菜单识别，子项筛选还要求锚点具有特定链接属性；启动也等待文档 complete，可能受其他 iframe 加载影响。

此次允许原生无 href 锚点，增加左侧菜单唯一“课程”目标的独立识别，保留原生点击、不拼接网址。文档完成 DOM 解析且菜单与内容 iframe 已出现即可尝试。仍仅下次访问自动打开，同次只点击一次，手动导航取消；未能识别或确认时在设置区显示原因。文档根节点 `data-cx-default-course-status` 同步简短状态供后续只读诊断。

# 学习通三合一脚本 v1.03

交付文件：`学习通AI助手.user.js`。原始三个 `.txt` 文件未修改。

## 安装或更新

1. 在油猴管理面板打开现有「学习通 AI 学习助手 - DeepSeek JSON」编辑器。
2. 用交付 `.user.js` 的全部内容替换原代码并保存。名称改为「学习通 AI 助手」，namespace 和存储键沿用旧值。
3. 停用独立的「超星字体解密」「学习通后台播放优化」，避免重复运行。
4. 刷新学习通章节测验。课程顶部出现「学习通AI助手」，测验标题右侧只显示「一键生成答案」；独立测验页保留自身助手入口。
5. 打开「学习通AI助手」核对 Key、模型和其他设置；如果油猴将它作为新脚本安装且未继承存储，需要重新填写 Key。

## 行为

- 一键按钮生成并预填，执行时显示圆形加载指示，不弹流程确认。
- 元数据加入 `@homepageURL`，指向 `https://github.com/zhu-hailin/chaoxing-ai-assistant`；更新并保存油猴脚本后，管理列表可读取此项目主页。
- 助手左侧加入课程目录栏，从可读取的同源祖先页面读取全部目录节点，包括原页面折叠隐藏的子章节。支持搜索、展开收起、当前章节标记和委托原页面入口跳转；运行分析或预填时禁用章节跳转。
- 完成状态直接读取原目录完成标记和待完成任务数；分组显示其子章节完成数量。已完成测验的最终成绩从 `.ceyan_name .Finalresult i` 读取，按课程、班级、账号、章节与测验分别记录在油猴存储中；仅展示实际读取过的成绩，不根据任务完成状态推断分数，也不自动遍历请求所有章节的成绩。支持零分、小数以及同章节多个测验。
- 宽窄屏均默认收起目录，入口为标题下方左侧的侧栏图标，点击展开或收起。目录搜索和列表具有独立滚动区域。独立测验页无法读取父级目录时显示说明，原提取和分析功能保留。
- 顶层 `mooc1.chaoxing.com/mycourse/studentstudy*` 学习页在 `#mainid #iframe` 内容上方加入「学习通AI助手」入口；视频和资料页可打开设置与目录，无本地测验题目时禁用提取和分析。章节内容被动态替换后重新挂载入口，不在播放器子框架创建重复入口。
- 不设置总题数上限，处理当前文档已载入的全部题目；不会自动翻页。默认每批最多 10 题，题目 JSON 长度超过批次预算时提前拆批，单道长题保持完整。
- 所有批次成功后才统一预填。任一批请求失败或题目发生变化时停止本次流程，不使用此前批次的局部结果自动预填。
- 设置与结果面板在测验内容区水平居中、顶部与测验标题附近对齐；不再靠页面底部。再次点击入口或按 Escape 可关闭。
- 加密容器中的题型标签与正常中文保持原文，仅转换字体中有自定义字形的字符。未知加密字形仍会阻止分析。
- 已完成结果页可能保留 `font-cxsecret` 类但显示明文；当没有字体声明且没有已知混淆字符时跳过解密，不再误报缺少字体。
- 原模型列表、深度思考、强度和联网检索功能保留。仅提取题目及等待 AI 生成时，展示题干和选项列表，不显示原始 JSON；生成后在对应题目下补充 AI 答案与解析。列表可滚动；复制按钮改为「复制列表」，复制可读文本。模型请求与校验仍使用结构化 JSON。
- 已按用户要求移除网络检索旁的说明、结果区底部的合并与预填保护说明，以及项目介绍中指定的 API Key 与费用说明；免费说明和网络检索复选框保留。
- 预填前校验题目 ID、题干和选项；已有不同答案或非空填空保留。无法确认的页面状态单独报告。
- 不主动点击保存或提交。原页面选项点击事件可能执行平台自身行为。
- 视频优化仅拦截顶层学习页鼠标移出导致的暂停，不包含标签页切换/失焦，也不主动播放视频。
- 字体模块使用原 TyprMd5 和字体表外部资源；资源不可用或字形映射缺失时停止分析。
- 字体解密部分源自 wyn665817 的 MIT 脚本；保留署名与 MIT 元数据。

# 学习通三合一脚本 v1.01

交付文件：`学习通AI助手.user.js`。原始三个 `.txt` 文件未修改。

## 安装或更新

1. 在油猴管理面板打开现有「学习通 AI 学习助手 - DeepSeek JSON」编辑器。
2. 用交付 `.user.js` 的全部内容替换原代码并保存。名称和 namespace 保留原值，存储键保持兼容。
3. 停用独立的「超星字体解密」「学习通后台播放优化」，避免重复运行。
4. 刷新学习通章节测验。标题右侧出现「一键生成答案」和「学习通AI助手」。
5. 打开「学习通AI助手」核对 Key、模型和其他设置；如果油猴将它作为新脚本安装且未继承存储，需要重新填写 Key。

## 行为

- 一键按钮生成并预填，执行时显示圆形加载指示，不弹流程确认。
- 不设置总题数上限，处理当前文档已载入的全部题目；不会自动翻页。默认每批最多 10 题，题目 JSON 长度超过批次预算时提前拆批，单道长题保持完整。
- 所有批次成功后才统一预填。任一批请求失败或题目发生变化时停止本次流程，不使用此前批次的局部结果自动预填。
- 设置与结果面板在测验内容区水平居中、顶部与测验标题附近对齐；不再靠页面底部。再次点击入口或按 Escape 可关闭。
- 加密容器中的题型标签与正常中文保持原文，仅转换字体中有自定义字形的字符。未知加密字形仍会阻止分析。
- 已完成结果页可能保留 `font-cxsecret` 类但显示明文；当没有字体声明且没有已知混淆字符时跳过解密，不再误报缺少字体。
- 原模型列表、深度思考、强度、联网检索、JSON 输出和复制功能保留。联网按已保存设置执行，可能产生额外模型费用。
- 预填前校验题目 ID、题干和选项；已有不同答案或非空填空保留。无法确认的页面状态单独报告。
- 不主动点击保存或提交。原页面选项点击事件可能执行平台自身行为。
- 视频优化仅拦截顶层学习页鼠标移出导致的暂停，不包含标签页切换/失焦，也不主动播放视频。
- 字体模块使用原 TyprMd5 和字体表外部资源；资源不可用或字形映射缺失时停止分析。
- 字体解密部分源自 wyn665817 的 MIT 脚本；保留署名与 MIT 元数据。

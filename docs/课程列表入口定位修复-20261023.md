# 课程列表入口定位修复

日期：2026-10-23。版本保持 1.30。

## 已确认原因

用户在真实页面执行的只读诊断确认：

- 顶层为 `https://i.chaoxing.com/base`，新版课程队列及三卡片面板已加载。
- `frame_content` 文档可读，实际课程列表为 `/visit/interaction`，35 张课程卡片及搜索框均存在。
- 唯一的“学习规划助手”为 `a.fr.assistantBtn`，它和搜索框共同属于 `.btn_group.tab_index_style`。
- 工具栏位于 `.course-list-con` 中，规划助手不在 `#courselistArea` 内。因此原 `#courselistArea .btn_group` 返回空，挂载流程提前退出。

## 修改

仅修改功能源码 `sources/course-list.js`：

1. 增加内部 `courseListEntryContext()`，从唯一的 `#searchInput` 查找所属 `.btn_group`，要求该工具栏内恰有一个归属一致的原生规划助手。
2. 复用原有入口样式和浮动布局，在原生规划助手之后插入助手节点，从而显示在其左侧。
3. 复用现有初始化及观察链，挂载条件失效时移除失效入口；点击前重新核对当前工具栏、规划助手与入口的关系。
4. 课程列表 URL 限制、课程卡片与内部身份解析、私有 GM 绑定和一次性队列交接保持原样。

更新 `CHANGELOG.md`，通过原构建器生成根目录完整用户脚本；README、版本、接口候选版、配套扩展及发布目录不改动。

- 统一设置原生禁用状态、简短原因及辅助阅读描述。鼠标悬停、点击禁用控件或其关联标签时，在控件附近显示白底短提示；提示不改变布局、不获取焦点。
- 复用原按钮资格判断，覆盖题目侧栏、分析／预填、失败重试、模型设置与选项、API Key、版本检查、课程启动／停止／跳过和运行设置。无可选模型的自绘列表按钮同步显示禁用与加载说明。

- 支持动态控件及封闭凭据输入区域；不读取输入内容，不在提示中显示 API Key。接口候选版同样使用本次共用模块。

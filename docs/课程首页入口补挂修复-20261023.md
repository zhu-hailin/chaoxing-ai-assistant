# 课程首页入口补挂修复

用户随后反馈本轮修改仍未显示入口。控制台确认父页面直接读取章节文档触发 SecurityError，后续改为章节本地挂载与私有消息交接，见 [首页章节域隔离适配](首页章节域隔离适配-20261023.md)。以下保留首次静态修改记录。

## 现场与原因

只读查看用户当前课程首页 DOM：顶层已经存在版本 1.30 的助手主面板；章节 iframe、原生搜索框及 `.chapter_head` 均存在，但 iframe 内没有 `cx-ai-course-home-toolbar`。入口没有创建。

源码中入口仅由章节 iframe 内的初始化流程挂载，并额外要求完整目录解析、父子文档关联及 referrer 判断全部通过；顶层页面只创建面板，没有补挂入口的路径。任一前置条件在该次初始化中未就绪，入口就会缺失。现场未采集到具体返回分支，本次修复入口归属及补挂链路，不根据脱敏的隐藏字段推断身份错误。

## 修改

- `sources/course-home-launch.js`：由首页控制器创建章节区域入口，单独核对顶层首页、当前 `frame_content-zj`、声明和已加载章节地址及课程／班级／cpi 的 URL 关联。显示入口独立于目录完整性与启动资格；点击时重新检查 frame、document、课程身份及入口节点，再打开既有主面板。启动与目录的完整身份校验保持原样。
- `implementation.js`：顶层主面板初始化后主动挂载入口；已有 iframe load 观察链在重新加载或替换后再次执行。章节 iframe 不再负责创建这个界面入口，继续保留原有导航交接适配。
- `course_catalog.js`：复用现有目录观察与刷新链补挂入口，覆盖章节内容后续更新；相同节点不重复插入，不增加轮询。

入口仍位于原生搜索框左侧。保留可信点击、助手整体显隐、目录选择、原生导航、运行锁、授权消费及任务执行流程。

## 交付

仅构建主脚本：`python build_script.py`。版本保持 1.30；README、接口候选版、配套扩展及发布工作树不改动。未提交、推送或发布。

本轮只读查看原页面 DOM，并静态审查源码、调用链及差异；未运行测试、语法检查、浏览器功能验证或真实 API 请求。

待用户手动验收：安装最新完整脚本并刷新课程首页，检查搜索框左侧入口、点击打开主面板、切换章节栏目或 iframe 更新后的入口恢复，以及隐藏／显示助手设置和原学习页入口。

# 待刷滚轮逐项切换

用户反馈：鼠标滚轮一次会滑动两张卡片。版本保持 1.30。

## 原因与修改

`createCourseWheel` 原来只监听 scroll，根据浏览器原生滚动后的像素位置计算高亮项，再由 CSS 吸附。原生滚动量受系统滚轮设置及连续输入影响，会越过一张卡片。

本次仅修改 `sources/course-run-preview.js`：

- 在组件自身注册非被动 wheel 监听，对普通纵向滚动阻止默认行为和向外传播，直接以当前滚动位置对应索引加／减一，复用既有 center 方法。
- 输入按正负方向判断，不将 deltaY 的绝对值直接转为多个卡片；同一 180ms 窗口中的重复信号合并，避免原生滚动与居中动画叠加。
- 课程范围或真实当前项变化时重置输入窗口。首尾仍由 center 的既有边界限制处理。
- Ctrl／Shift 修饰、横向为主的输入及不能取消的事件继续交给浏览器；点击、方向键、触摸和窗口尺寸变化继续走原处理链。
- 监听只改变滚轮浏览位置，不写入课程选择、不调用启动、跳过或导航。

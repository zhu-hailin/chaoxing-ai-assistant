# P0 改进与模型标识

2026-10-13。v1.12 发布改动，基于 main 的 e866237；脚本版本从 1.11 递增为 1.12，npm 版本同步为 1.0.12。

## 使用变化

- 自动提交默认关闭，不读取旧的开启配置。每次运行须在主页面实际勾选，并通过浏览器原生确认；权限只用于本次开始或重试，页面刷新与导航恢复不继承。
- 课程命令保存在脚本闭包中，不再接收网页派发的启动、重试、跳过、停止事件。模型调用、预填、停止分析等按钮也校验真实控件事件；事件类型、原生 currentTarget 和事件路径必须对应实际控件。
- 课程主页面增加「课程控制」入口，章节测验窗口存在时仍能返回主运行器。独立子测验脚本显示状态，课程操作在主页面进行。
- 人工或来源不明的暂停等待手动播放，不自动恢复。仅助手自身因当前任务明确的前台观看要求产生的暂停可在返回后恢复；等待时间不计入媒体或连续学习预算。显式平台异常、访问受限等提示仍停止运行。
- API Key 从篡改猴菜单「设置 / 替换模型 API Key」和「清除模型 API Key」编辑。菜单要求明确选择六个平台之一；已保存的 Key 不回显。课程 DOM 只显示保存状态。浏览器原生输入框中新输入的 Key 可见，不能当作密码掩码输入框。
- 自定义 Key 绑定已授权的完整 HTTPS 基础地址。地址变化或历史 Key 缺少绑定时，须从菜单重新设置；预置平台旧 Key 保留。移除 `@connect *`，自定义域名通过篡改猴的逐域授权/用户域名白名单使用。声明 `@sandbox DOM` 优先采用扩展隔离环境。
- 不匹配脚本的外部学习页面中若嵌入匹配的题目 iframe，该题目页也提供带独立短编号的凭据菜单，避免合并回调引发多个弹窗。

## 品牌标识

DeepSeek、OpenAI、通义千问、Kimi、GLM 的图标来自官网或官网引用的 CDN，没有绘制或生成。平台列表、答题模型列表、识别模型列表的每个预置选项均显示其平台 Logo；自定义不显示。

原始资源、下载地址与 SHA-256 保存在 [标识来源记录](../assets/provider-logos/provenance.json)。ICO 转换后的 PNG 与原文件像素一致；图标内嵌脚本，运行时不下载图片。列表支持键盘方向键、Home/End、Enter、Escape、Tab 和文本定位，并同步配置值与禁用状态。

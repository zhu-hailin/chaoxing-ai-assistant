学习通有识别异常学习的能力及实际处理记录，检测不依赖截图这一种途径。已有公开证据包括学习时长与完成状态不一致、作答时长异常、IP跨度异常及多终端学习异常；视频防窗口切换、章节学习监控与考试抓拍也有公开说明。没有取得本脚本被检测、当前课程持续截屏、或先前暂停与回退由某一防护触发的证据。

## 截图和网页权限需要分别判断

1. **普通Chrome网页采集整个桌面、窗口或其他标签页**：标准 `getDisplayMedia()` 要求用户交互，并由用户选择共享对象、授权新采集会话；不能把许可永久保存后静默重新开启。一次共享会话启动后可持续采集，因此不能说“每张截图都需要弹窗”。这些约束针对普通网页的标准API，不涵盖用户另外授权的扩展、原生客户端、管理软件或浏览器漏洞。[屏幕采集API](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)。
2. **摄像头抓拍**：与桌面采集不同。网页使用摄像头需要权限，先前保存的站点许可可能允许以后直接开启；没有出现新弹窗不等于没有摄像头使用，应看浏览器指示及站点权限。[摄像头权限说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。
3. **网页自身内容采集**：页面原本能访问本页DOM。类似html2canvas的库可根据DOM和样式生成页面图像，并不是真正的系统屏幕截图；跨域与渲染限制仍存在。页面读取DOM、表单和播放状态并不需要桌面共享许可。没有发现学习通当前课程使用此库的证据。[html2canvas原理](https://html2canvas.hertzen.com/documentation)。
4. **页面可见性和焦点**：网页能通过标准可见性API判断切换标签页、最小化等状态，无需截屏；窗口失焦与页面不可见并非同一件事。[Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)。

## 对当前脚本的只读源码评估

- `implementation.js:339、544` 与 `sources/assistant-core.js:39`：工具栏和面板添加到课程文档，使用固定宿主ID及open Shadow DOM。根据共享DOM规则，页面脚本从技术上可读取这些节点、面板文案和开放的内部结构。这只是可观察性，尚未确认学习通扫描这些标记。收起或隐藏面板不会消除服务器学习记录，也不能当作反检测保证。[Chrome共享DOM说明](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[shadowRoot访问规则](https://developer.mozilla.org/en-US/docs/Web/API/Element/shadowRoot)。
- `sources/assistant-core.js:317、318、363`：答案预填派发input/change事件，部分选择使用元素click。浏览器的 `isTrusted` 可区分某些合成事件；但单一事件字段不能完整证明用户行为，未确认学习通用它识别本脚本。[事件来源说明](https://developer.mozilla.org/en-US/docs/Web/API/Event/isTrusted)。
- `implementation.js:2–11`：后台播放逻辑阻断一类mouseout事件。这不能说明其他页面状态监听或服务器统计也被屏蔽，不能据此宣称不会被检测。
- `sources/course-video-info.js:3`：当前抽帧读取播放视频并转为图像，是本项目的资料识别流程；不能与学习通监考截图混为一谈。涉及外部视觉模型，应限制为获准资料并保持可关闭，不发送个人摄像头或桌面。
- `implementation.js:505–511、614–617`：已保存Key不会自动填回设置输入框，保存后重绘清空输入框；这一点已有保护。输入新Key期间，它仍暂存在页面内开放的输入节点，密码掩码只影响显示。若加强隐私，应把凭据编辑迁移到独立受信设置页，而不是把改成closed Shadow DOM视为安全边界。本轮没有读取任何真实Key，也没有证据显示平台读取过该输入框。
- 当前任务适配器遵循平台完成标记，不自行构造任务上报；这是数据完整性保护，但正常获得一次完成标记仍不能保证后续平台审计认可自动学习。

## 建议采用的防护方向

建议以减少误判、保护凭据与资料、尊重课程规则为目标，不承诺脚本隐身或零检测。

1. **先限定允许的操作范围**：正式考试、身份核验和明确禁止自动操作的课程使用平台原流程；人脸、验证码、视频交互题及异常提示由人工处理。若教师启用了前台观看要求，遵守其要求，不伪造可见性或焦点。
2. **保持学习数据真实**：继续禁止写入视频进度、伪造时长、修改任务完成状态及构造完成上报；同一时间一门课程，并避免多终端同时学习。该措施降低数据冲突，不意味着允许使用工具或保证通过审计。
3. **恢复有边界且尊重人工暂停**：区分媒体缓冲、播放器定位、身份检查和平台明示暂停；不把所有暂停都自动解释为可恢复的故障。反复恢复无有效进展、显式规则提示或平台异常时停止，保留简要原因，避免无限重试。具体改动需另行设计与用户授权。
4. **减少资料和凭据暴露**：现有Key不回填继续保留；优先将Key编辑放入独立受信界面。抽帧和课程资料发送提供清晰开关、模型目的地和费用说明；只发送回答问题必需的资料，不包含账号参数、Cookie、摄像头或桌面内容。
5. **误判保留可复核证据**：仅记录事件类型、相对时间、播放位置、真实速率、页面可见性、媒体状态和平台任务结果；不记录带签名的资源地址、登录凭据或完整答卷。异常学习记录可联系课程教师或平台客服核查，平台公开教程支持教师纠正监控误判。

未取得的证据包括：当前课程监控配置、当前页面实际采集与上传的字段、隐藏服务器检测算法、脚本身份扫描及本账号异常记录。本轮仅形成研究记录，没有实施上述建议、修改脚本或README、升级版本、上传GitHub或做真实课程检测实验。

## 2026-10-11：授权后的界面隐藏与运行控制

以上保留只读研究阶段的结论。本节记录随后获得用户实施授权的本地修改，脚本保持 1.09。

已加入油猴菜单“隐藏助手全部界面”和“显示助手界面”。隐藏配置 `cx_ui_hidden` 与窗口模式、模型配置及运行配置独立；通过存储变更监听同步页面与嵌套测验。菜单接口和跨实例存储通知依据 [Tampermonkey 菜单文档](https://www.tampermonkey.net/documentation.php?q=GM_registerMenuCommand) 与 [存储监听文档](https://www.tampermonkey.net/documentation.php?q=GM_values)。

隐藏作用于助手宿主，包括主窗口、悬浮圆、课程入口、测验生成按钮及助手状态文字。正常流程继续执行，错误和结束不会自动恢复界面。显示菜单恢复宿主原有内联样式，并打开当前页面对应的主窗口。隐藏时取消悬浮拖动与停止确认倒计时。

本功能仅控制界面显示。没有通用的截图前通知，因此未实现截图发生时自动隐藏，也未拦截截图、Canvas、网络或屏幕采集。助手 DOM 保留，网页仍可能访问本页节点、事件与媒体状态；隐藏不能证明平台无法识别自动操作。

视频适配器现在只根据当前视频任务附近可见的明确观看限制决定是否等待前台；隐藏说明、题干、其他任务和反复暂停本身不作为限制证据。要求前台时暂停真实视频，等待顶层页面可见且有焦点；等待期间不重复启动播放，并排除相应的停滞、定位、重播与累计学习预算。诊断事件仍使用真实时间。已删除此前阻止 `mouseout` 传播的逻辑，没有伪造页面可见性、焦点、播放进度或平台完成状态。

学习休息默认关闭，可保存连续学习和休息时长；仅在成功结束章节且还有后续待处理章节时触发。固定休息截止时间随运行会话保存，刷新恢复不重新计时。

本次内置浏览器的离线截图显示：隐藏后没有助手窗口、悬浮圆和课程入口；测试预览页自有的模拟菜单按钮仍保留。Chrome 当时有扩展界面占用自动化，因此该项没有取得 Chrome 真实课程证据。当前课程的监控配置、采集行为和实际菜单跨页效果仍待用户现场验收，未进行真实课程检测实验。

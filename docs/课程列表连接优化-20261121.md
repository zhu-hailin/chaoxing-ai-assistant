# 课程列表连接优化

截图中官网已经显示课程卡片，助手仍在连接。静态审查发现，父页对已有连接中的子页就绪通知没有立即发起读取，而 `frame_content` 的 `load` 会无条件重建连接。

- 子页通信就绪后独立通知父页，父页立即发送现有请求，轮询只作兜底。
- 同节点、同地址且尚无已接受快照的连接保留请求、监听和期限。已有快照或 iframe 发生变化时重新绑定，启动前仍核对当前文档和原生课程入口。
- 重连时暂时隐藏选择计数，保留本页勾选。新列表到达后按当前可选项核对选择。

本地版本维持 v1.34。已静态审查握手、超时重连、旧响应及选择状态，并构建主脚本。`tests/course-list-connection.cjs` 补充了就绪通知、首次加载和旧快照用例，尚未执行。

真实页验收时，刷新个人空间，核对官网课程卡片出现后助手列表的显示速度。重连后确认相同的可选课程仍被勾选。

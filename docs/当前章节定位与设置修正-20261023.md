## 当前章节定位

- 在章节目录的「刷新」旁增加「定位当前」，只在目录页显示。
- 点击时重新读取原目录中唯一的当前章节；清除搜索筛选，展开其父分组，滚动至对应条目。
- 滚动只作用于助手内目录，不滚动课程页面，也不调用章节导航或控制运行任务。
- 条目增加短暂描边与「已定位」标记，按钮和目录状态行同步反馈，1.8 秒后恢复正常显示。
- 自动目录刷新期间沿章节 ID 与课程范围保留短暂反馈；重复点击重置反馈时间，页面离开时清理定时器。
- 没有明确当前章节时只在目录状态行显示简短原因，不猜测或点击其他章节。
- 沿用原搜索、折叠、目录更新及导航禁用逻辑；用户要求减少动态效果时使用即时滚动。

# 课程首页启动自动学习

后续已扩展首页目录同步与未完成任务直达，见 [后续实现记录](首页目录同步与未完成任务直达-20261023.md)。下文保留首次接入时的实现记录。

## 接入方式

以本地最新源码为基础，在 HTTPS `mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu` 单门课程首页的章节内容顶部、搜索框左侧挂载入口（按用户标注调整，移除左侧课程名下的旧入口）。入口位于 `studentcourse` iframe 的 `.chapter_head`，点击后通过核对 iframe 来源、窗口及课程身份的消息打开顶层首页既有面板；不创建第二个面板。该消息仅切换界面，启动仍须通过原有可信点击和授权流程。

新增 `sources/course-home-launch.js`，通过现有课程控件的可选适配器接入。首页仅配置、导航和交接，到达学习页后直接调用原 `courseRunner.start(options)`；任务定位、章节处理、视频、资料、测验、运行锁、顺序解锁和异常停止均保留原实现。`studyOwnerDocument()` 与对外插件 API 未扩大。

首页的“从当前开始”仅禁用显示，不覆盖其持久设置；题目、暂停、跳过与重试继续依据实际能力禁用。等待期间“停止”显示为“取消启动”。原生目录保留在平台页面。

## 原生入口

已在方案阶段通过只读 DOM 观察确认：章节 iframe 为 `frame_content-zj`，章节项为 `.chapter_item#cur{章节ID}`，处理函数为 `toOld(课程ID,章节ID,班级ID,...)`。实现核对参数、DOM 身份与原生 ServerHost 指定的受支持课程服务器，再点击原节点；平台负责 transfer 与实际学习地址的构造。

若尚未进入章节栏目，点击已确认的原生“章节”入口。导航落点取首个具备可靠原生能力的章节，不在首页另做任务定位或完成判定。验证码、人脸、登录异常、已显示的学习承诺界面等需先由用户处理，不自动确认。

## 一次性交接

- 通过新增的 `GM_getTab` / `GM_saveTab` 权限保存标签页身份，随机启动记录存于同脚本私有 GM 存储，包含课程／班级／cpi、期限、章节、冻结选项及模型配置／Key 指纹，不保存 API Key。
- 同标签页经过跨域 transfer 或刷新后读取原记录。新标签原生链接使用一次性 fragment；原生处理函数打开的新窗口使用 opener + 私有 GM 信箱握手。不能可靠关联时不自动领取。
- 每 500ms 检查，整个交接最多 120 秒，刷新与节点变化不重置期限；接收方核对已加载课程 iframe、目录、模型签名及原有阻断条件。
- 通过目标来源下的请求互斥锁单次消费；调用原运行器前清除持久记录中的自动提交授权，授权只留本次调用的内存参数。消费后不重复启动。
- 首页启动与原 `resumeIfNeeded()` 串行决策；无首页记录时沿用原恢复，有交接时不同时恢复旧任务。后续正常导航恢复仍保持原有自动提交权限处理。
- 取消、新启动替代、身份变化、失败和过期会终结原交接；晚到回调和重复命令不会重新导航。

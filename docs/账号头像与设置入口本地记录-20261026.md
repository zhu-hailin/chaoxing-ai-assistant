## 读取与保护边界

- 新增 sources/account-profile.js 并纳入完整脚本构建；原始账号资料不写 GM 持久设置。
- Cookie 仅读取 UID、_uid、fid、spaceFid、siteRole、spaceRoleId 六个数字字段，其余字段不进入账号对象、界面、网络参数或诊断记录。
- 当前个人空间优先直接读取既有 DOM。其他页面先使用当前数字用户标识显示平台头像，仅用户点击头像时才 GET https://i.chaoxing.com/base 获取姓名和单位资料，不在面板初始化时新增账号请求。
- 接受的资料响应限定 HTTPS i.chaoxing.com /base，检查状态、内容大小及姓名；头像限定 HTTPS photo.chaoxing.com 的数字用户路径，头像与当前 UID 不符时清除展示并提示刷新。
- 资料使用 textContent 渲染，头像不传页面 referrer，只保留平台头像路径及数字 temp 参数；服务器 HTML 不直接注入面板。
- 关闭弹层、页面退出和较早的异步返回受到代次控制；关闭或隐藏助手时同步关闭账号弹层，避免原生 modal 阻挡页面。恢复焦点及 Esc 处理沿用现有窗口方式。

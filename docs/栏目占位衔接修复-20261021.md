## 用户现场与根因

用户截图中，自动学习停在 1.1 绪论，原因是“栏目加载时当前任务页面已变化，请重新开始”。该文字对应 `processChapter()` 内 `refreshTabs()` 的占位栏目迁移分支。

上一轮栏目修复引入此回退：原生栏目未渲染时，队列先使用 `current`（“当前页面”）；随后真实栏目出现，保护逻辑却拿此时的 iframe/document/body/src 与章节进入时保存的 `initialContent` 比较。原生加载期间更换文档也会命中该比较，直接中止整轮。另一处相关问题是将占位页的已处理记录直接赋给新 active 栏目，可能跳过尚未重新读取的真实任务。

## 修改

- 仅修改 `sources/course-runner.js` 的占位栏目衔接；真实栏目出现后，撤销临时占位身份的已遍历记录，不把它的结果映射为真实栏目完成。
- 若正在处理占位页，结束该页的后续任务遍历或完成等待，回到原有栏目循环；重新取得真实栏目、iframe、任务控件及平台完成状态。重绑定后复用原有有界加载等待；平台已完成任务仍按原流程记为 `already`。
- 真实栏目出现后仅发生一次身份衔接；后续继续使用真实 ID、`cardid` 和 active 保护。运行锁、课程/账号、换章、已确认栏目移除/切换、原生禁用、控件生命周期与提交保护保留。
- 移除原来把临时页任务改记为新 active 栏目任务的逻辑，避免继承未经核实的完成状态。

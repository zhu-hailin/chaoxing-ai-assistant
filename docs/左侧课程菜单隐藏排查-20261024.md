# 左侧课程菜单隐藏排查

用户要求在其他功能里自动获取原生左侧菜单，逐项提供开关，开启后隐藏对应原生菜单；先用代码排查现场结构。

已静态阅读 `sources/other-features.js`：目前只有隐藏平台 AI 助教和手动播放保护，开关通过私有 GM 设置保存、跨页面通知并在面板中绑定。原生菜单的结构及导航入口尚待用户现场诊断。

新增 `work/diagnostics/左侧课程菜单诊断.js`，供用户在截图所示课程首页的控制台 top 执行。读取左侧已知菜单标签所在节点、父级链、共同容器、可见性、原生链接路径、参数名、点击处理函数名及 iframe 声明地址。查询参数值和片段不输出，不输出课程标题、账号姓名、凭据、完整 onclick 或 data 属性值；长数字 ID 用占位符替代。

诊断只读取 DOM，不触发点击、隐藏、网络请求或存储写入；未在浏览器中执行，未运行测试或语法检查。主脚本、版本、README、接口候选版及配套扩展保持原样，未构建、提交或发布。

后续已收到用户现场诊断：具体课程页使用 `#boxscrollleft .stuNavigationList > ul`，独立 `li` 包含带 `data-url` 的原生 `a`，原生菜单由委托事件处理；不同用户的数量、文字及顺序可能不同。

已据此实现动态菜单识别、逐项隐藏及原生打开操作，并补充按结构及左侧位置识别的适配。个人空间侧栏隐藏按用户要求取消；另增加独立的“默认打开课程”开关。详见 [实现记录](课程菜单隐藏与默认打开课程-20261024.md)。此处诊断结果来自用户执行，代理仅静态阅读并构建主脚本。

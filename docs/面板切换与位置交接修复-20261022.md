# 侧栏切换与窗口位置交接

日期：2026-10-22。版本：1.28.1，未发布。

## 实际原因

现场复现时，嵌套测验面板保存着七道题。进入刷课后打开的是另一个顶层课程控制器；返回题目只切换了顶层控制器的本地视图，其 sourceDoc 为课程主文档，因此列表为空、提取按钮禁用。原七题仍在隐藏的测验面板中。

两个面板打开时分别按入口锚点定位，现场窗口下移约 20 像素。已在修改前恢复到原七题测验面板。

## 修改

业务源码仅修改 implementation.js：

- 在既有显示事件上补齐双向导航，接收方只执行本地视图切换，避免事件往返。
- 课程控制器记住进入时的测验来源；返回时在当前课程可见、同源 iframe 树中优先查找该文档。旧来源不再存在时重新查找当前测验。
- 无有效测验、跨域或接收方尚未就绪时保持当前窗口；目标打开后由既有窗口激活事件隐藏原窗口。
- 交接面板的实际坐标、尺寸与键盘焦点要求，写入已有 userPosition、userSize 后沿用原定位及视口约束。
- 顶层工具栏在课程面板打开时复用交接流程；关闭或最小化状态下保留原有测验窗口切换方式。
- 不修改 sourceDoc，不重建控制器，不重新提取或渲染题目，不复制答案、任务或预填快照；导航不启动或停止分析、预填及学习任务。
- 独立测验仍走本地视图切换。拖动、缩放、最小化、关闭和重新打开继续使用原有窗口机制。

## 用户手动验收

- 安装新构建后，七题列表往返切换仍保留，提取按钮状态正常，窗口坐标和尺寸稳定。
- 拖动、缩放后往返切换，检查题目列表滚动位置、已有答案、逐题进度及预填资格保留。
- 关闭重开、最小化恢复及键盘导航保持正常。
- 换章节、测验 iframe 替换或目标尚未就绪时，确认返回当前有效测验，旧结果不套用到新题目。

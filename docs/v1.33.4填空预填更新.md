# v1.33.4 填空自动识别与顺序预填

日期：2026-11-04。基线：上游 main 的 e12bacf3cedff15b8da537f983f471d4a629269c（v1.33.3）。

## 问题与结果

旧版 doHomeWorkNew 的一题多空包含多个独立 UEditor，原实现要求整题只有一个编辑器，因此整题跳过。原生空位另有可见 InpDIV 与待展开 textDIV，单空及多空都可能处于收起状态。

本次按原生空位及唯一、连续的可见空号自动识别数量和顺序，逐空绑定既有字段、编辑器及原生入口；同题多空一次模型请求，各空按稳定 ID 返回完整答案后再顺序预填。单空保留原题 ID；未知隐藏结构或不可靠关联继续人工处理。

写入前通过原生入口展开并重新校验，继续 setContent + sync 和内容/正文/textarea 回读。已有不同答案、只读或禁用、实例或节点变化、人工介入、答案缺失及同步不明仍阻止覆盖或停止后续填写。界面按题汇总，内部作答区域计数保留给课程执行器；同时处理重试、暂存恢复和原题检索来源。

# 课程启动位置修复

个人空间选择线性代数 A 并开始后，有时停在该课程主页的「任务」栏目。原实现只在创建启动记录时尝试点击一次「章节」，后续只等待章节 iframe。

- 启动交接期间按当前页面重新定位唯一的原生章节入口。首次点击两秒后仍未切换时，最多再点一次。十秒内未切换会停止本次启动并给出提示。章节已选中且目录还在加载时沿用原等待期限。
- 只向当前可见、地址及身份匹配的章节 iframe 发送启动请求。使用原目录读取、起始章选择、章节锁定与学习页交接。
- 课程主页缺少常规标题节点时，只有匹配当前课程、班级和账号的有效启动队列可以补挂交接面板。

本地版本维持 v1.34。已审查启动交接调用链和差异，并构建主脚本。已添加隐藏 iframe、一次重试、重复入口和取消启动的专项用例，尚未执行。

现场验收从个人空间选择线性代数 A 并点击开始，核对从「任务」切换到「章节」后进入所设起始章。

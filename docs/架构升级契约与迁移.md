## 数据契约

Schema 3 顶层为 questions / materials / media / controls / relations / bindings / lifecycle。
问题保留旧简单字段，并增加 structure、blocks、responseUnits、sharedMaterialIds、supportLevel。
内容块支持 text/image/math/table/code/slot/subquestion/instruction/shared-context；图片仅引用 mediaId。
只有实际读到的公式、表格与已证明的题组材料进入请求。输入内容、DOM、运行时映射和资源签名地址不作为内容块发送。

控件描述与原生 Node 分离。原生文本、radio、checkbox 和既有章节 writer 可写；select、上传、富文本和 Canvas 仅识别。
关系为 confirmed/probable/ambiguous/unsupported，只有 confirmed 可写。
明确 label 引用要求唯一 ID、真实 label.control 和题目边界；数组次序、距离、重复文本不能提供确认依据。
多输入无明确槽位映射时仍交人工。混合可写与未适配作答区会保留未解决单元，不能整份提交。

supportLevel 包含 Fully Supported / Partial Support / Analyze Only / Manual Required / Unreadable / Unsupported。
结构能力与人工题规则独立；计算推导、手写上传等限制不会被 Schema 或模型 auto 结果覆盖。

buildQuestionRequestUnits(graph) 返回 questions/media/bindings/parentByUnit/unitsByQuestion。
简单题保留原 ID；复合单元使用快照内唯一 ID，沿用现有 answers 协议。
结果保留执行用的单元答案，并生成 questionAnswers 供原题卡片显示；界面分别显示原题及作答区域数量。

## 生命周期与执行

任务身份不由反馈、按钮显隐或已选答案生成。内容签名排除作答状态；控件身份独立校验。
Document 导航、节点替换、题干/材料/关系变化使旧计划失效。显式重试创建新的取消信号，再验证原冻结内容；不会重放已确认的旧批次。
快照只在当前页面保留。iframe 关系通过 frameElement 链提供证据，失效、不可读或超界为 unknown。
courseTaskContains 保留 Boolean API，内部委托公共关系查询。

规划不 focus、不点击、不填值。执行前预检完整计划，每次写入前再校验；原生 setter/click 后必须回读。
计划实际 Node 存于 WeakMap，执行结束移除监听并清理私有计划。中途取消保留已发生的真实输入，不自动回滚。
章节入口不允许 ownedAnswers 覆盖。视频弹题只允许同一节点、脚本上一轮拥有且用户未改动的答案替换。

## 错误与诊断

error.code 保留 NETWORK/TIMEOUT/HTTP/COURSE_TIMEOUT 等控制语义，error.cxCode 提供稳定目录码。
HTTP 非成功先分类为 HTTP，再处理成功响应 JSON、必要字段、业务错误、截断和答案协议。
原有 NETWORK/TIMEOUT/502/503/504 的授权分析重试仍最多一次、间隔两秒；不增加 429 自动重试。

诊断最多 100 条，仅本页面内存，刷新清除；同一 Error 向上传播只记录一次。
固定目录文案配合数量、阶段、关系证据和 HTTP 状态白名单。独立 cx-task / cx-request 本地 ID 可关联请求；业务课程/账号 ID 不导出。
cause 和响应关联元数据仅存私有 WeakMap。安全复制排除题干、答案、媒体、HTML、Cookie、Key、部分 Key、原始响应与完整 URL。
开发者页的“复制错误报告”和“复制运行摘要”使用安全投影；有意复制题目答案的“复制列表”仍是独立入口。
原有完整课程详情仅供本地查看。目录错误文案与历史本地阶段原因分开，安全报告始终使用目录文案。

## 配置与集成边界

选择自定义平台时，在接口地址旁提示：篡改猴管理面板 → 本脚本 → 设置 → 用户域名白名单，添加 AI API 主机名。
不添加 @connect *，不将普通网络失败直接认定为白名单缺失。内置平台继续动态获取模型，不新增型号预设。
模型列表 GET 现受页面取消与身份检查保护，迟到响应不能保存过期模型列表。

视频弹题保留 v1.19 tkTopic、原生按钮白名单、六次确认上限、新反馈基线及未知结果锁。
新增公共快照检查和安全写入；播放、进度、回退、倍速、休息、章节导航及平台完成逻辑未重构。
关闭章节自动提交仍直接跳过测验；完成仍由平台确认。

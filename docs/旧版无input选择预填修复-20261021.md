# 旧版章节测验无 input 选择预填修复

日期：2026-10-21。追加到本轮本地修复，版本保留 `1.26`，以 `D:\Project\xuexitong` 当前源码为准。

## 实际根因与调用链

现场 `/mooc-ans/work/doHomeWorkNew` 为一题单选、四题多选。题目真实 ID 已唯一识别，本次保留既有题目 ID 生成逻辑，未使用页面 `data="0"/"1"` 改写 ID。

完整链路为：`rawQuestion → finishQuestion → parseQuestionGraph → createQuestionSnapshot → AI 分析 → prefillChecked → planQuestionActions → questionActionChapterCheckbox`。

原 `questionActionChapterCheckbox()` 以 `li.before-after-checkbox` 作为入口条件，再要求每行唯一 checkbox、`answercheck+题目ID` 及 `addcheck(题目ID)`。现场选项实际使用 `addMultipleChoice(this)` 且没有 input，在该函数原有结构校验处抛出 `CX-MAT-005`。错误发生在整份无副作用计划建立期间，执行器尚未开始写入，因此已分析的五题全部留空。

## 修复方式

1. 原生 checkbox 分支必须出现 `addcheck` 调用或对应命名原生控件，继续保留其唯一组、题号、字段和 200ms 异步同步校验。
2. 为旧版指定路由增加无 input 行选项绑定：单选严格对应 `addChoice(this)`，多选严格对应 `addMultipleChoice(this)`；从所属行唯一 `label.fl.before` 读取实际字母，核对 `a.fl.after`、`div.clear`、题目边界、唯一字母和处理函数。已有 `.num_option`、原生 input、mooc2 和视频弹题适配路径继续沿用原分支。
3. 新绑定进入题目图的既有 `chapter-choice` 控件和确认关联。处理函数、原生控件标识、标签/正文节点、保存字段与表单身份保存在页面私有快照中；变化时旧计划失效，这些 DOM 绑定不进入 AI 请求。
4. 执行仅点击经核验的原生选项行，依靠平台处理函数完成选择；不直接修改选中 class、隐藏答案或任务完成状态。
5. 每次操作后有限等待并读取选项行/字母标记的选中状态；存在唯一同题原生保存字段时，同时核对其合法字母集合与选中集合。状态冲突、未确认或页面变化即停止后续动作。
6. 已有不同或部分人工答案保持原样。未适配静态结构在完整快照未变化时逐题跳过；所有可执行单元仍在首次写入前完整校验，页面变化和执行期异常继续安全中止。
7. 成功、跳过和未确认结果按题记录；异常时携带部分成功摘要，面板保留已生成的 AI 答案及逐题写入结果。本次预填不点击提交。

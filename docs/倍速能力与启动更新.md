# 倍速能力与启动更新：实现及验收记录

日期：2026-10-15。基于本地当前架构候选，保持 v1.19 / npm 1.0.19。本次没有拉取远端源码、提交、推送、打标签或发行。

## 实现

- 自动刷课增加“开启倍速”，默认关闭，保存为 `cx_course_speed_enabled`。运行中禁改；导航接力保留本轮选项，旧会话缺字段时关闭。视频信息识别开启时整轮不启用倍速，面板显示原因。
- `courseVideoSpeedCapability()` 为每个真实 video 返回 `allowed/disabled/unknown`。从当前 `.video-js` 已有实例读取 `options().playbackRates`，与对应原生菜单逐档核对；不使用任务完成状态、视频下标或跨文档 id 匹配。
- `false` 且无冲突表示未开放；配置缺失、尚未就绪、菜单不完整、绑定不明或信息冲突均 unknown。明确禁止倍速的当前任务可见提示优先阻止。检测随既有播放轮询重新执行，不新增观察器或定时器。
- DOM 沙箱通过新增的 `unsafeWindow` 授权只读访问已有页面播放器；沿真实 frameElement/同源 iframe 链查找，使用 isSameNode 验证 DOM 身份。读取失败时 unknown，禁止创建新 Video.js 实例或绕过跨域限制。
- `courseApplyVideoSpeed()` 仅选择原生最高不超过 2x 的 >1 档位。需要时显示播放器自己的菜单，再点击经核验的菜单项并回读；不写 video.playbackRate、不调用播放器速率 setter、不操作播放位置。不点击可能循环切换速率的菜单总按钮、不抢焦点。每个菜单项/配置最多尝试一次，平台拒绝或恢复原速后不反复改速。
- 倍速选择只接入已完成原有弹题、前台、定位、结束和暂停检查的正常播放路径。任务记录保留固定能力、档位、目标和结果字段。视频弹题、手动暂停与前台等待不操作倍速菜单。
- `startQuizObserver()` 的启动入口调用一次异步 `startAssistantUpdateCheck()`，与面板创建无关。顶层 Document 的首次自动检查使用 force=true 绕过24小时缓存；iframe、面板重复初始化及 BFCache 恢复不发第二次自动请求。刷新/新开 Document 可再次检查。
- 保留原有更新源、元数据/版本/标签脚本核验、匿名请求、取消和手动检查。检查失败不阻塞使用；只显示现有下载入口，用户决定安装。同号远端内容不执行或写入本地文件。
- 使用现有构建拼接，无需改写 build_script.py。prepare_publish.py 只补充未来发布所需的测试/结果清单，本次没有运行发布准备。

## 现场待验收

以上为本地模拟，不代表真实油猴沙箱/学习通播放器验收。真实 Video.js 版本或定制菜单缺少可核验字段时保持 unknown/原速；需要有真实DOM证据后再补适配。

1. 在允许操作、没有人脸或验证码的课程，关闭视频信息识别并开启倍速，验证原生有2x/最高1.5x的视频分别保持2x/1.5x，配置false的视频保持原速；核对持续进展及平台完成状态。
2. 核对同页多个视频、章节切换及嵌套 iframe，查看开发者报告的能力和选择结果；检查手动暂停、弹题、隐藏及前台门槛。

4. 刷新后不打开面板，检查匿名更新请求；同页打开/关闭面板不重复请求，无更新不弹窗；新版只显示下载入口，网络失败不影响使用。

## 2026-10-15 现场倍速菜单兼容修复（当前交付）

### 现场证据与根因

用户截图显示助手已开启倍速，原生菜单提供2x但仍选中1x。只读浏览器报告确认当前视频为 `unknown / menu-conflict`，并非信息识别互斥。当前页面引用 Video.js 7.2.2；已采集该视频所属原生菜单DOM到 `tests/fixtures/video-speed-chaoxing-menu.html`，不包含账号、媒体地址或页面令牌。

确认的缺陷是：旧实现只从 `button.items` 和每个组件的 `options().rate` 建立菜单绑定；现场真实菜单未通过这项校验。浏览器只读DOM接口没有暴露这些组件内部属性，因此不声称已经现场确认了某一个内部字段具体缺失。新回归模拟“组件不暴露items/内部rate”的情况，旧检测器25项中有4项失败；新实现全部通过。

### 修复

优先读取当前已绑定播放器按钮下现场确认的 `.vjs-menu-content[role="menu"] > .vjs-menu-item[role="menuitemradio"]`，仅从唯一 `.vjs-menu-item-text` 读取档位；不把“选择”等辅助文字或字幕菜单混入。与当前播放器实际配置进行完整、唯一的档位核对。老格式继续使用原组件适配；配置false、禁用、未知、重复/非法标签、所属关系变化仍不操作。

选择仍为原生菜单点击，不写 `playbackRate`，不改变视频暂停、进度、前台判断、弹题、导航或完成逻辑。运行开关、信息识别互斥、最高不超过2x、重复尝试限制保持原规则。

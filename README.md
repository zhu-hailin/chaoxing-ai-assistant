# 学习通AI助手

**Chaoxing AI Assistant** · 免费的学习通网页端学习辅助脚本

配合篡改猴（Tampermonkey）使用

当前版本：**v1.05**。程序展示截图来自 v1.04，功能与操作入口沿用。

支持以下主要功能：

1. 章节测验、课程作业AI一键答题
2. 全自动学习通刷课

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| 本地解析架构 | 页面适配器和题型解析器生成统一题目模型，章节与已适配的作业结构共用流程；未知题型保留诊断，不连带阻止其他题目。 |
| 作业简答题 | 支持简答、问答、论述标签及中英文括号；正文和图片题均可提取，普通单文本框可保护性预填。 |
| 题目图片 | 支持单选、多选的纯图片选项，原图与解析显示在对应选项内；同一作业题组共用题干图片并标明来源，选项图片不跨题共享，排除答案区图片。 |
| 图文分析 | 使用所选模型；无视觉能力时跳过图片题，纯文字题继续分析，不自动切换模型。支持图片的模型可返回表格或条目形式的图片内容解析。 |
| 一键生成与预填 | 依次完成字体处理、题目提取、AI 分析、校验和预填，显示加载状态及批次进度。 |
| 多题分批分析 | 支持当前页面已加载的全部题目，每批最多 10 题、约 12000 个文本字符；组合材料超限时分批，单题保持完整，所有批次成功后统一预填。 |
| 分批进度与重试 | 每批成功后立即显示结果；网络错误、超时或 HTTP 502/503/504 在 2 秒后自动重试一次，仍失败可点击“重试未完成”。成功批次、检索材料和已读取图片在当前页面内存中复用，不重新请求；刷新、重新提取或题目/分析配置变化后不复用。修正 Key 后可继续失败批次。 |
| 停止分析 | 普通分析支持停止图片读取、检索、模型请求及重试等待；保留已成功结果，全部可分析批次成功前不预填。预填期间停止会保留已写内容。关闭窗口不等于停止分析。 |
| 题目与答案列表 | 提取后显示题干、选项及图片，生成后补充答案与解析；复制可读文字和图片来源说明，不复制图片地址或 Base64。 |
| DeepSeek 设置 | 支持获取模型列表、切换模型、深度思考、推理强度和联网检索。 |
| 三页图标导航 | 顶部标题栏固定，左栏上方是题目、章节，底部是模型设置；默认打开题目页，未配置时提示先配置模型。图标悬停显示名称，支持键盘上下键切换。 |
| 课程目录 | 在章节页查看完整目录；支持搜索、分组展开收起、当前章节标记和点击跳转。 |
| 课程自动学习 | 在章节页点击开始后，依次处理多视频、可识别的 PPT/资料和章节测验，完成后进入下一目录；没有视频或测验的文字页面也可遍历。 |
| 自动流程报告 | 支持停止和复制报告，记录已完成任务及无法自动填写的具体题号；遇到人脸识别、验证码、页面变化或提交结果不明时停止；允许超时继续时记录未完成章节并进入下一节。 |
| 完成状态与成绩 | 显示页面提供的完成状态及待完成任务数；测验成绩仅展示实际读取并记录过的分数。 |
| 窗口拖动与缩放 | 按住标题栏空白处移动；拖动右边缘、下边缘或右下角调整大小。顶部 GitHub 图标可打开项目主页。 |
| 视频进度与静音 | 底部展示正在播放的视频时间和只读进度条；「关闭视频声音」默认开启，不改变播放速度或进度。 |
| 学习开关保存 | 五个学习控制开关保存在油猴存储中，刷新或重开页面恢复；本次运行使用启动时的配置。 |
| 字体解密 | 处理混淆题干和选项；无法可靠还原时停止分析并提示错误。 |
| 视频后台播放优化 | 常规模式处理鼠标移出学习页导致的暂停；用户启动自动学习后正常播放视频，读取实际进度与结束状态，并尝试恢复中途暂停。 |

支持单选、多选、判断、单个文本框填空及普通文本框简答。预填会保留不同的手工答案和非空填空内容；未知题型保留在列表中等待适配；无效选项或不确定的控件跳过预填。多空与富文本暂不自动填写。普通一键生成不主动点击保存或提交；自动学习模式仅在整份章节测验可靠预填后，按「自动提交章节测验」选项操作原页面提交按钮，并等待明确的提交成功状态。

图片分析目前识别 DeepSeek Flash 的视觉能力，Pro 等无视觉能力的模型暂不处理带自身或共用图片的题目。图片只在开始分析后读取并随请求发送；图片损坏、读取失败、材料超限或题目变化时，保留题目列表并中止本次应用。支持网页 `<img>` 中的 PNG、JPEG、GIF、WebP，不包含 PDF、视频、Canvas 或手动上传。真实图文回答和新作业布局仍需安装后现场测试。

选项只有图片、没有文字时仍按原 A、B、C、D 对应提取、分析和预填，模型请求和联网检索携带选项归属；相同图片去重后也保留所有对应选项。选择无视觉能力的模型时，该题暂不分析。图片与控件无法可靠对应时明确跳过，不猜测选项。

## 安装与使用

**[点击一键安装 / 更新脚本](https://github.com/zhu-hailin/chaoxing-ai-assistant/raw/HEAD/%E5%AD%A6%E4%B9%A0%E9%80%9AAI%E5%8A%A9%E6%89%8B.user.js)**

先安装并启用篡改猴，再点击上方链接，在弹出的脚本安装页确认安装或更新。链接获取 GitHub 当前公开版本；未上传的本地修改请使用下方手动安装方式。

如果未弹出安装页，可按以下步骤手动安装：

1. 在浏览器中安装篡改猴（Tampermonkey）。
2. 打开 [脚本文件](学习通AI助手.user.js)，将完整代码粘贴到篡改猴的新建脚本编辑器中并保存。更新旧版时，在原脚本编辑器中替换代码。
3. 刷新学习通课程页面，点击「学习通AI助手」，点击左栏底部的模型图标，保存自己的 DeepSeek API Key，选择模型及其他设置；也可通过题目页的「配置模型」提示进入。
4. 进入章节测验或作业，点击「一键生成答案」。作业页按钮位于白色卡片标题区右侧；图片题先选择支持图片的模型。等待分析与预填完成后，核对答案和跳过项，再自行决定是否保存或提交。

视频或资料页可以打开设置与课程目录；没有测验题目时，提取和分析按钮不可用。独立测验页保留自身的助手入口。

在课程学习页面打开「章节」，点击「开始刷课」运行课程自动流程。建议先在模型页完成设置；未配置时可以处理视频和资料，遇到测验会停止并提示配置。「自动提交章节测验」默认勾选，取消后在预填结束时停留供人工提交。遇到问卷等需人工操作的章节，可以点击「跳过本章节」继续下一章；报告保留用户跳过记录，不计为完成。流程因本章问题停止后，也可在当前章节点击该按钮续接原队列；测验提交结果尚未确认时不可跳过。点击「停止」中止流程，结束或异常停止后在「运行报告」查看并复制统计与需人工处理的题号。

### 学习控制开关

| 开关 | 初始默认值 | 行为 |
| --- | --- | --- |
| 自动提交章节测验 | 开启 | 整份测验可靠预填后操作原页面提交入口，并等待平台确认；关闭时保留预填结果供人工提交。 |
| 自动跳过已学 | 开启 | 跳过已学章节及已完成的视频、资料；关闭可进入已学内容测试。已提交测验始终不重复作答。 |
| 从当前开始 | 关闭 | 开启后以当前选中的章节作为本次起点；后续导航恢复使用本次原队列。 |
| 超时是否继续下一节 | 开启 | 超时后记录原因并继续下一章，不将超时章节计为完成；关闭时停止。提交结果不明、人脸验证等仍停止。 |
| 关闭视频声音 | 开启 | 播放前将视频设为静音；关闭则取消静音，保留原音量。 |

以上开关修改后自动保存；运行中不可修改，需先停止再调整。用户跳过与超时跳过均会保留在报告中。

自动学习先启动原播放器，再等待视频时长加载，正常播放，不跳进度或调整倍速。同章多任务按页面顺序处理，支持视频与 PPT 混合、多个任务 iframe 和多个页面标签。已经完成或提交的章节测验跳过作答，仍继续本章其他任务；确认无任务点的资料直接进入下一节。PPT 支持原分页按钮到末页，以及连续图片阅读区域逐步滚到底（含已确认的新版跨域文档阅读器），仍需读取到平台的任务完成状态；控件不支持或状态缺失时保留诊断；被明确归类为超时的情况按「超时是否继续下一节」设置处理。独立作业页、人脸识别和验证码需要人工处理。正常导航可在同一浏览器会话续接队列；主动离开、刷新或切换章节会停止。

本地 [自动课程模拟页](tests/自动课程模拟.html) 用于验证流程；其中视频进度、模型回答和任务完成状态均为合成数据。已现场确认一处新版跨域连续图片 PPT 能逐步滚动、获得平台完成标记并进入下一章；这不代表所有课程页面均已适配。本轮静音与开关保存通过模拟回归，真实图文调用和更多页面的兼容性仍需现场核对。具体证据见 [验证记录](docs/验证记录.md)，流程设计见 [自动课程架构](docs/自动课程架构.md)。

左栏上方第一个图标打开题目和答案列表，第二个打开章节目录，底部图标打开模型设置。默认展示题目页；未保存 Key 或未选择模型时提示先配置，点击分析会进入设置页。题目提取和目录查看无需配置模型。切换页面保留输入、结果和滚动位置；章节页顶部提供「学习控制／章节目录」两个子页，控制按钮和报告在左页，搜索、完成状态及测验分数在右页。标题栏可拖动位置，右边缘、下边缘及右下角可拖拽调整窗口大小；同一面板关闭重开保留尺寸。底部显示运行状态及当前视频只读进度，未知时长或非视频阶段隐藏进度条。浏览和调整大小不会解除正在进行的请求锁定。

Key 保存在油猴脚本存储中，不显示在题目列表及复制内容中。当前脚本名称为「学习通 AI 助手」，namespace 和存储键沿用旧值；在原脚本编辑器内更新可继续使用原设置。如果被安装为新脚本，可能需要重新填写设置。

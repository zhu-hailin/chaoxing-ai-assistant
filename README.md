# 学习通AI助手

**Chaoxing AI Assistant** · 免费的学习通网页端学习辅助脚本

本项目仅供参考与学习，需要配合「篡改猴」（Tampermonkey）使用的学习通辅助脚本。它将超星字体解密、视频后台播放优化和 DeepSeek AI 学习辅助整合到一起，帮助提取章节测验题目、分析答案并一键预填，让常用功能集中在一个脚本内。

目前仅支持DeepSeek。

## 功能介绍

1. **视频后台播放优化**：处理学习页中鼠标移出网页导致的视频暂停，保留页面原有的播放控制。当前功能范围不包含切换标签页或窗口失焦，也不会自动启动视频。
2. **章节测验 AI 分析与一键预填**：点击测验标题右侧的「一键生成答案」，依次完成字体处理、题目提取、AI 分析、结果校验和预填。不再限制为 25 题，支持当前页面的全部题目，默认每批最多分析 10 题，长题目自动拆成更小批次。执行过程中显示圆形加载指示和批次进度，所有批次成功后统一校验与预填，完成后提示已填写、跳过及需要核对的题目数量。
3. **内置超星字体解密**：处理混淆题干和选项，帮助还原题目文本。已完成测验的明文结果页不会仅因保留字体标记而被误判；无法还原的内容仍会提示错误。
4. **DeepSeek 设置与结果查看**：支持获取模型列表、切换模型、深度思考、推理强度和联网检索设置，也可以查看或复制题目与 AI 答案 JSON。
5. **已有答案保护**：预填前重新核对题目 ID、题干和选项，保留不同的手工答案及非空填空内容。脚本不会主动点击保存或提交；处理结果需要自行检查。

本项目暂时只支持 **DeepSeek**。当前支持现有章节测验结构中的单选、多选、判断及单个文本框填空；未知题型、无法对应的选项或不确定的输入结构会停止分析或跳过预填。

## 使用方法

1. 在浏览器中安装篡改猴（Tampermonkey）。
2. 新建脚本，将 `学习通AI助手.user.js` 的完整代码粘贴到编辑器中并保存。已有旧版 AI 助手时，在原编辑器内替换代码即可。
3. 刷新学习通页面，进入章节测验，点击「学习通AI助手」配置自己的 DeepSeek API Key，并核对模型及其他选项。
4. 点击「一键生成答案」，等待分析和预填完成，再自行核对答案与跳过项。是否保存或提交由使用者操作。

Key 保存在油猴的脚本存储中，不显示在题目和答案 JSON 内。更新时保留旧版名称、namespace 和存储键；如果油猴将其作为新脚本安装，可能需要重新填写设置。
